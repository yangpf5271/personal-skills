# 视频制作链路审查

像一个虚拟制作公司，出片前每个角色从自己专业角度审一遍。不只是"好不好看"，而是"这个角度有没有问题"。

## 职责边界

- `video-spec-builder` 负责生成 spec → **你负责审查 spec 和实施结果**
- `hyperframes` 负责合成编排 → **你负责检查合成质量**
- `motion-design` 提供动效原则 → **你负责检查动效用对了没有**
- 你不是"再做一遍"，你是"换一双眼睛看"

## 启动检查

1. 确认项目根目录有 `video-spec.md`
2. 确认视频已进入"可审查"状态（spec 已定稿，或已有预览/渲染输出）
3. 读取 `video-spec.md` 了解原始意图

你不需要等渲染完成才能审查——spec 定稿后就可以对"纸上"的设计做多角色审视，避免到渲染才发现问题。

## 7 个审查角色

按依赖顺序排列，前一个角色的结论可能影响后一个：

### 1. 选题策划 — "这个选题本身站得住吗"

审查维度：
- **受众匹配**：目标观众看了会觉得"这跟我有关系"吗？不是"我想讲什么"，是"他们想听什么"
- **信息差**：这个选题有没有给观众新信息？还是老生常谈？
- **钩子强度**：前 3 秒能不能让人停下滑动？B 站的算法只看"3 秒留存"
- **选题时机**：这个时间点发合不合适？蹭到热点了吗？
- **竞争环境**：同类视频多不多？你的差异化在哪？

输出格式：
```
[选题策划] 评分：X/10
✅ 做得好的：
❌ 有风险的：
💡 建议：
```

### 2. 事实核查 — "每个说法站得住吗"

审查维度：
- **数据来源**：每个数字/统计有没有出处？标了来源吗？
- **时效性**：引用的数据是今年的还是三年前的？
- **技术准确性**：涉及技术的说法有没有明显错误？（代码逻辑、API 名称、版本号）
- **产品信息**：产品功能/定价/限制描述准确吗？有没有过时的？
- **免责边界**：主观判断有没有标明是"个人观点"？

输出格式：
```
[事实核查] 评分：X/10
✅ 准确无误的：
⚠️ 需要核实/补充来源的：
❌ 明显错误的：
💡 建议：
```

### 3. 技术实现 — "开发者视角，这能跑吗"

审查维度：
- **可实现性**：spec 里提的效果技术上能不能做？（对照 [能力对照表]）
- **性能**：这个视频在目标设备上会不会卡？有没有帧率风险？
- **渲染可行性**：涉及 WebGL / shader / Three.js 的镜头，浏览器兼容性如何？
- **素材链路**：TTS 音频、抠像、转场，整条链路有没有断点？
- **边界条件**：极端文案长度、超长时间轴、大量元素同屏 —— 踩到坑没有？

输出格式：
```
[技术实现] 评分：X/10
✅ 技术上没问题的：
⚠️ 有风险但可绕过的：
❌ 当前方案做不了的：
💡 替代方案：
```

### 4. 视觉设计 — "看起来对不对"

审查维度：
- **设计一致性**：颜色 / 字体 / 字重 / 间距 / 圆角跟 design.md 或预设一致吗？
- **对比度**：文字在背景上能看清吗？有没有灰字铺灰底的？
- **信息层级**：观众第一眼看到的是最重要的东西吗？有没有"不知道该看哪"
- **排版**：字号梯度合理吗？行长会不会太长/太短？中英文混排对齐了吗？
- **空帧检查**：有没有镜头画面里什么都没发生的"真空期"？

输出格式：
```
[视觉设计] 评分：X/10
✅ 做得好的：
⚠️ 需要调整的：
❌ 明显有问题的：
💡 建议：
```

### 5. 审美品味 — "好不好看，高不高级"

审查维度：
- **色调协调**：主色和辅色搭不搭？有没有"辣眼睛"的撞色？
- **留白与密度**：信息密度合理吗？是拥挤到窒息还是空旷到无聊？
- **质感**：扁平、渐变、毛玻璃、3D——风格统一吗？还是大杂烩？
- **字体品味**：选的字体跟内容气质搭吗？有没有"宋体配科技"这种违和？
- **"廉价感"检测**：有没有 clipart 风格的图标、默认箭头、彩虹渐变这类减分项？

输出格式：
```
[审美品味] 评分：X/10
✅ 做得好的：
⚠️ 可优化的：
❌ 拉低档次的：
💡 建议：
```

### 6. 节奏控制 — "观众会不会中途划走"

审查维度：
- **开场节奏**：前 3 秒有没有钩子？前 10 秒有没有给出"继续看"的理由？
- **信息密度曲线**：有没有"拖沓"的段落？有没有信息轰炸让人想关掉的段落？
- **转场节奏**：转场频率合适吗？连续快切后面有没有给喘气的空镜？
- **情绪曲线**：是否有起有伏？还是一直高能到麻木，或者一直平淡到划走？
- **结尾处理**：有没有明确的收尾？结尾有没有引导（关注 / 三连 / 看下一个）？

输出格式：
```
[节奏控制] 评分：X/10
✅ 做得好的：
⚠️ 需要调整的：
❌ 节奏断了的地方：
💡 建议：
```

### 7. 平台包装 — "B 站观众买不买账"

审查维度：
- **标题**：够不够吸引点击？有没有数字/悬念/冲突？但有没有标题党嫌疑？
- **封面**：三要素齐全吗（主视觉 + 标题文字 + 情感信号）？小图能看清吗？
- **前 15 秒**：B 站完播率最关键的就是前 15 秒，这 15 秒能不能让人不走？
- **弹幕预判**：哪些画面/台词会被截图做表情包？哪些地方会被刷"？？？"或"哈哈哈哈"？
- **互动设计**：视频里有设计互动点吗？（引导讨论 / 投票 / 二创空间）
- **分区与标签**：投的区对吗？标签打够了吗？有没有蹭到正确的流量池？

输出格式：
```
[平台包装] 评分：X/10
✅ 做得好的：
⚠️ 可以更强的：
❌ 有硬伤的：
💡 建议：
```

## 审查流程

```
1. 读取 video-spec.md，了解原始意图和每个镜头的设计
2. 从角色 1 到角色 7 逐层审查（不必全部走完——审查到你认为没问题的层级即可）
3. 每个角色输出格式化的审查结论
4. 汇总：输出一个优先级排序的修改清单
5. 询问用户："要针对哪些问题修改 spec？还是全部采纳直接改？"
```

## 输出规范

### 每个角色必须回答
- **评分**：1-10 分（不是敷衍的全 7 分——好就是好，差就是差）
- **具体的**：不说"节奏不好"，说"第 3 镜到第 5 镜之间连续 12 秒没有信息增量"
- **可执行的**：每个 ❌ 必须配一个 💡 具体建议

### 说人话
- 不说"信息密度不足"，说"观众这时候已经在刷手机了"
- 不说"视觉层次不清晰"，说"第一眼看过去不知道该看哪"
- 不说"钩子强度弱"，说"前 3 秒像讲座开场，B 站观众不会等的"

### 汇总清单格式
```markdown
## 审查汇总

总分：XX/70（7 角色 × 10 分）

### 🔴 必须改（影响完播率或准确性）
1. ...
2. ...

### 🟡 建议改（显著提升质量）
1. ...
2. ...

### 🟢 锦上添花（有余力就做）
1. ...
2. ...
```

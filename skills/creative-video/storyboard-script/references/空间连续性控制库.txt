空间连续性控制库
references/空间连续性控制库.txt ｜ V1.1
════════════════════════════════════════════════════════════

【为什么需要这个库】
AIGC 视频生成模型没有跨镜头记忆。每个镜头、每个视频段都是独立生成的。
如果空间和状态信息只写一次，后续镜头省略，模型会随机重建空间——
人物从床右跳到床左、背景人物忽坐忽躺、角色凭空消失。
解决方法：用固定格式的锚定标签，在每镜提示词最前面强制复写。

【四大根因 → 四层锁定】
根因1：无空间锚 → 每镜重新理解空间 → 位置随机
根因2：状态未锁定 → 背景人物被省略 → 忽坐忽躺
根因3：跨视频零交接 → 模型记忆清零 → 人物消失/移位
根因4：道具状态未锁定 → 杯子换手/衣服开合乱跳/道具凭空消失

══════════ SECTION:L1-空间锚定 ══════════
第一层：空间锚定串（每个场景写一次，每镜强制复写）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
像"身份锚定串"锁定人物外貌一样，空间锚锁定场景的物理布局。
一旦确定，同场景内每个镜头的提示词都必须在开头复写，一字不改。

■ 格式
[空间锚]场景名，核心家具位置，门窗方位，关键角色固定位置

■ 写法规则
- 只写空间关系，不写动作、不写情绪
- 位置用绝对方位（左/右/中央/前景/后景），不用"旁边""附近"
- 每个固定角色的位置在空间锚里锁定
- 角色移动后，更新空间锚中的位置

■ 数值坐标模式（可选·增强精度）
当绝对方位词不够精准时（多角色同框易穿模 / 模型位置理解偏弱 / 需精确控制间距），
在绝对方位词后追加数值坐标，不是替代是叠加：
- X轴横向占比XX%（0%=画面最左，100%=画面最右）
- Y轴纵向占比XX%（0%=画面最上，100%=画面最下）
- 身体朝向XX度（0°=正对镜头，90°=右侧身，180°=背对镜头，270°=左侧身）
- 写法示例：[空间锚]病房，病床纵向居中(X50%/Y60%)，门在画面右侧(X85%)，
  窗户在画面左侧(X15%)，刘翠花半卧病床左侧位(X30%/Y55%/朝向90°)
- 通用性：可灵/即梦/Vidu/海螺/LibTV等主流模型均支持百分比坐标描述

■ 示例（产房场景）

[空间锚]产房，产床横向居中放置，门在画面右侧，窗户在画面左侧，
刘翠花半卧于产床左侧位，婴儿床在产床右前方

■ 示例（病房场景）

[空间锚]病房，病床纵向居中放置，门在画面右侧，窗户在画面左侧，
桌椅在画面右侧靠墙，刘翠花半卧病床左侧位，婴儿床在病床右侧

■ 复写规则
- 逐镜模式（C）：同场景内每个镜头提示词的开头强制复写空间锚
- 全局模式（A/B/D）：空间锚放全局前缀块输出一次，逐镜不重复；角色移动时在画面描述中写明方向
- 如果角色在该镜中有位置变化，空间锚中更新该角色的位置（逐镜模式）或在画面描述中标注变化（全局模式）
- 切换场景时，重写新的空间锚
- 跨视频拆分时，新视频第一镜必须复写空间锚（两种模式均如此）

■ 常见错误
✗ "翠花躺在床上" → 太模糊，没说是床左还是床右
✗ "翠花在病房里" → 没有空间关系
✓ "刘翠花半卧于产床左侧位" → 绝对方位，可复写

══════════ SECTION:L2-人物状态 ══════════
第二层：人物状态锁（每镜列出全部角色状态，未变化也要复写）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
背景角色的姿态如果不写，模型会随机生成——
镜1躺着、镜2坐着、镜3又躺下。
状态锁强制每镜列出场景中所有角色的身体姿态，
即使该角色不在画面焦点中，也要写"画外+姿态"。

■ 格式
[状态锁]角色A=姿态/位置，角色B=姿态/位置，角色C=画外（位置不变）

■ 姿态词库（只用以下标准词，禁止自由发挥）
体位：站立/行走/坐下/半卧/平躺/侧卧/蹲下/弯腰/前倾
修饰：不动/微动/缓步/快步/僵住/定格
位置：画面左侧/画面右侧/画面中央/前景/后景/画外
位置（数值坐标·可选）：X轴横向占比XX%/Y轴纵向占比XX%/朝向XX度
      与绝对方位词并用，如"画面左侧(X30%/Y55%/朝向90°)"

■ 写法规则
- 场景中出现的每个角色都要列出，不管是否在画面焦点中
- 不在画面中的角色写：画外（位置不变）
- 角色状态与上一镜相同 → 照抄，不要省略
- 角色状态有变化 → 写出新状态，并在画面描述中说明变化过程
- 状态锁放在空间锚之后、画质风格之前

■ 示例（镜8：刘翠花看婴儿）

[状态锁]刘翠花=半卧位/画面左侧不动，婴儿=平躺/婴儿床不动，
护士=画外（门口方向不变）

■ 示例（镜12：王建国冲进病房）

[状态锁]刘翠花=半卧位/画面左侧不动，王建国=快步入画/从右侧门方向，
婴儿=画外（婴儿床不变）

■ 示例（镜15：王建国僵在婴儿床前）

[状态锁]刘翠花=半卧位/画面左侧不动，王建国=站立/弯腰前倾定格/画面中央，
婴儿=平躺/婴儿床不动

■ 关键规则
1. 背景人物的状态绝对不能省略——这是"忽坐忽躺"的唯一原因
2. 即使上一镜已经写了"半卧位"，这一镜必须照抄，不能写"同上"
3. 角色离开场景时，状态锁改为：角色X=已离场（不再列出）
4. 新角色入场时，状态锁增加该角色行

══════════ SECTION:L3-服装道具 ══════════
第三层：服装道具连续性锁（每镜列出全部角色的道具和着装状态）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
身份锚定串锁定"脸长什么样"，空间锚锁定"站在哪"，状态锁锁定"什么姿态"。
但没有人锁"穿什么状态、拿什么道具"——
镜1角色外套敞开→镜2扣上了→镜3又敞开；镜5左手拿杯→镜6杯在右手→镜7杯消失了。
道具锁强制每镜列出所有可见角色的着装状态和手持道具。

■ 格式
[道具锁]角色A=道具/着装状态，角色B=道具/着装状态

■ 道具词库（只用以下标准词，禁止自由发挥）
手持：左手持XX/右手持XX/双手持XX/空手/放下XX/举起XX
着装：外套敞开/外套扣合/领口系/领口开/帽子戴正/帽子歪斜/发箍正位/发箍歪斜
佩戴：胸针别左领/胸针别右领/项链外露/项链内藏/手表左腕/手表右腕
状态：完好/污渍/撕裂/湿痕/褶皱/歪斜/脱落

■ 写法规则
- 列出场景中每个可见角色的道具和着装状态
- 不在画面中的角色写：画外（道具不变）
- 道具状态与上一镜相同 → 照抄，不要省略
- 道具状态有变化 → 写出新状态，并在画面描述中说明变化过程
- 道具锁放在状态锁之后、画质风格之前
- 角色"换装""受伤""被泼液体"等状态变化必须立即更新道具锁

■ 示例（镜21：知微松杯）

[道具锁]知微=右手刚松开空杯/外套扣合/胸针别左领/发箍无，
明珠=双手空/裙摆完好/珍珠发箍正位

■ 示例（镜19：明珠被泼茶后→镜20延续）

镜19：
[道具锁]知微=右手持茶杯/外套扣合/胸针别左领，明珠=双手空/裙摆完好/发箍正位

镜20（泼茶后下一镜）：
[道具锁]知微=空手/外套扣合/胸针别左领，明珠=双手空/前襟湿痕/发箍歪斜
→ 明珠的"前襟湿痕""发箍歪斜"必须延续到后续所有镜头，直到她换装

■ 关键规则
1. 持有道具的角色如果道具消失，必须在画面描述中写明道具去向（放下/丢失/被夺）
2. 受伤、被泼液体、衣服撕裂等物理状态变化是持久的——后续所有镜头必须保持
3. 同场景换装是极罕见的，如果发生必须用[道具锁]标注"已换装：XXX"
4. 道具锁不计入画面描述字数限制

══════════ SECTION:L4-跨视频协议 ══════════
第四层：跨视频交接帧协议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 适用场景
当镜头数超过单次生成上限（通常5-10镜/段），需要拆成多段视频时。
每段视频独立生成，模型不保留前段记忆，必须通过交接帧传递状态。

■ 交接三件套（每段视频的第一镜必须包含）

1. [交接]标签：引用前段最后一镜的末帧状态
   格式：[交接]前段镜N末帧：角色位置+姿态+道具状态一句话概括

2. 空间锚：完整复写当前场景的空间锚

3. 状态锁：列出全部角色的当前状态（从前段末帧继承）

4. 道具锁：列出全部角色的道具/着装状态（从前段末帧继承）

■ 示例（视频1为镜1-5，视频2为镜6-10）

视频2的第一镜（镜6）提示词开头：

[交接]前段镜5末帧：刘翠花半卧产床左侧，王建国站产床右侧低头看婴儿，
医生站床尾，翠花左手放被下，建国空手

[空间锚]产房，产床横向居中放置，门在画面右侧，窗户在画面左侧，
刘翠花半卧于产床左侧位，婴儿床在产床右前方

[状态锁]刘翠花=半卧位/画面左侧不动，王建国=站立/画面右侧不动，
医生=站立/画面后景不动，婴儿=平躺/婴儿床不动

[道具锁]刘翠花=左手放被下/病号服完好，王建国=空手/外套敞开，
医生=画外（道具不变），婴儿=裹襁褓

→ 后接画质风格 + 镜头参数 + 画面描述...

■ 图像交接法（更强的交接方式）

如果生成平台支持图生视频（image-to-video）：
1. 取前段视频最后一帧作为关键帧截图
2. 将该截图作为新视频第一镜的输入参考图
3. 在提示词中标注：[参考帧]前段末帧，保持人物位置和姿态一致
4. 仍然复写空间锚和状态锁作为文字层保障

■ 视频拆分规则
- 每段视频尽量在场景不变的位置拆分（同场景内拆）
- 如果必须跨场景拆分，在交接帧中说明场景切换
- 每段视频镜数建议≤5镜，最多不超过8镜
- 拆分点尽量选在角色状态稳定的镜头之间，不要在动作中间拆

══════════ SECTION:L5-环境光影 ══════════
第五层：环境光影锁（同场景光线/色温/光比/时间天气跨镜一致）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
AIGC 模型每镜独立生成，不保留前镜光影信息。
同场景第一镜写了"侧顺光5500K"，第二镜可能变成"逆光7500K"——
画面光线跳变，观众立刻出戏。光影锁强制同场景各镜维持统一光影设定，
同时锁定时间（黄昏/正午）和天气（晴/雨），防止同场景时间天气跳变。

■ 格式
[光影锁]时间+天气+主光方向/色温/光比/特殊光效

■ 写法规则
- 每个场景首镜建立光影锁，后续各镜强制复写
- 光源方向用绝对方位（左侧顺光/右侧逆光/顶光/底光）
- 色温数值化（5500K/3200K/7500K），不用"暖色/冷色"
- 光比数值化（文戏3:1/战斗6:1）
- 同场景内光影锁必须一致，除非剧情明确需要光线变化（如灯灭/日落/法术光）
- 光线变化时，在画面描述中说明变化原因
- 时间和天气同场景内绝对不变——"黄昏"不能在第五镜变成"正午"

■ 示例（产房场景·首镜）

[光影锁]午后/晴/左侧顺光5500K/光比3:1/无特殊光效

■ 示例（同场景·后续镜头）

[光影锁]午后/晴/左侧顺光5500K/光比3:1/无特殊光效（同上，不变）

■ 关键规则
1. 时间和天气同场景内绝对不变
2. 光源方向同场景内不变，除非角色移动到不同位置
3. 光影锁放在道具锁之后、画质风格之前
4. 光影锁不计入画面描述字数限制

══════════ SECTION:L6-环境声音 ══════════
第六层：环境声音锁（同场景环境音跨镜一致）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
同场景的环境底噪必须跨镜延续。
镜1有"风声+虫鸣"，镜3变成"寂静无声"，镜5又出现"街道嘈杂"——
声音跳变会让观众感觉场景不连续。声音锁强制同场景维持统一环境音。

■ 格式
[声音锁]环境底噪+持续音源

■ 写法规则
- 每个场景首镜建立声音锁，后续各镜强制复写
- 环境底噪：该场景持续存在的背景音（风声/虫鸣/雨声/街道嘈杂/机械嗡鸣）
- 持续音源：该场景中持续发声的物体（钟表嘀嗒/水流声/篝火噼啪）
- 同场景内声音锁必须一致，除非剧情明确需要声音变化（如突然安静=紧张感）
- 声音变化时，在音效字段中说明变化原因
- 动作音效（脚步/开门/击打）不锁，因为它们是每镜独有的

■ 示例（病房场景·首镜）

[声音锁]环境底噪：病房白噪音+监护仪嘀声｜持续音源：无

■ 示例（同场景·后续镜头）

[声音锁]环境底噪：病房白噪音+监护仪嘀声｜持续音源：无（同上，不变）

■ 关键规则
1. 环境底噪同场景内不变——不能这镜有风声下镜就没了
2. "突然静默"是特殊用法，必须标注"环境音骤停"并说明剧情原因
3. 声音锁放在光影锁之后、画质风格之前
4. 声音锁不计入画面描述字数限制

角色锚定串规范（身份锁定，跨镜角色一致性核心）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
空间锚锁定"站在哪"，状态锁锁定"什么姿态"，道具锁锁定"拿什么"。
角色锚定串锁定"长什么样"——跨镜角色面部和着装一致性的核心。
省略锚定串=模型每镜重新生成角色外貌=换脸/换装/瞳色漂移。

■ 标准格式
姓名+确切年龄+身份+发型发色+瞳色+服装关键词+配色

■ 示例
沈知微，24岁，黑长直低马尾，琥珀瞳，月白西装套裙，银色胸针，
主色冷蓝60%+辅色暖金30%+点缀银色10%

■ 写法规则
- 每镜原样复写，一字不改，禁止用代号缩写（模板C为终稿交付，尤其禁止）
- 全局参数块可定义角色代号（如"女主"），但提交生成时必须展开为完整锚定串
- 锚定串放在六层锁定标签之后、画质风格之前
- 锚定串不计入画面描述字数限制
- 截断优先级：最高——超预算时绝对不砍锚定串（砍了=角色长相变）

■ LibTV 简化格式（图生视频参考帧，适用于所有支持图生视频/参考帧的模型）
- 适用于：LibTV Star Video 2.0 / Seedance 2.0，以及可灵/即梦/Runway/Vidu 等所有支持图生视频的模型
- 不再每镜复写完整锚定串（50+字外貌描述）
- 改为：角色名【参考图1】+ 当前着装/状态差异
- 角色长相由参考图锁定，文字只补充参考图无法覆盖的变化（换装/受伤/道具）
- 详见 references/生成模型适配层.txt 第四节-B

══════════ SECTION:L7-锁定输出模式 ══════════
第七层：全局锁定模式 vs 逐镜锁定模式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 背景
六层锁定体系（L1-L6）原本要求每镜强制复写全部锁定标签。
当单次输出3-40段分镜时，每镜~200字纯锁定信息 → 30段=6000字纯重复。
引入"全局锁定模式"：不变的信息全局输出一次，逐镜只写变化项。

角色一致性卡库（references/角色一致性卡库.txt）定义角色卡格式和输出模式。
本节定义六层锁定标签在两种模式下的输出规则。

■ 两种模式

┌─────────────────────────────────────────────────────────┐
│ 全局模式（模板A/B/D）                                   │
│                                                         │
│ 全局前缀块（分镜正文之前，输出一次）：                  │
│   [角色卡]×N角色                                        │
│   [空间锚]场景布局+角色固定位置                         │
│   [状态锁]全部角色基础姿态                              │
│   [道具锁]全部角色基础道具/着装                         │
│   [光影锁]时间+天气+光源+色温+光比                     │
│   [声音锁]环境底噪+持续音源                             │
│   [全局防崩锁词(可选)]                                  │
│                                                         │
│ 各分镜正文：                                            │
│   - 不再复写锁定标签                                    │
│   - 仅在该镜发生状态变化时，在画面描述中标注变化        │
│   - 无变化时直接从画质风格开始                          │
│   - 场景切换时，新场景首镜前写新的[空间锚][光影锁][声音锁]│
│   - 跨视频拆分时，新视频首镜写[交接]标签+当前状态摘要   │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 逐镜模式（模板C）                                       │
│                                                         │
│ 每镜独立展开全部锁定标签（与原有规则完全一致）：        │
│   [角色锚定串] + [空间锚] + [状态锁] + [道具锁] +       │
│   [光影锁] + [声音锁] → 画质风格 → 镜头 → 画面描述...   │
│                                                         │
│ 每镜强制复写，即使无变化。18项自检清单逐镜过。          │
└─────────────────────────────────────────────────────────┘

■ 模式选择
| 模板 | 模式 | 锁定输出位置 | 复写策略 |
|------|------|-------------|----------|
| A | 全局 | 全局前缀块 | 仅写变化项 |
| B | 全局 | 全局前缀块 | 仅写变化项 |
| C | 逐镜 | 每镜字段 | 强制全量复写 |
| D | 全局 | 全局前缀块 | 仅写变化项 |
快速模式默认模板D → 全局模式。

■ 全局模式下各层的输出规则

| 锁定层 | 全局模式输出方式 | 逐镜变化项写法 |
|--------|-----------------|---------------|
| 角色锚定串 | →升级为[角色卡]，全局输出一次 | 不再逐镜复写；换装/受伤时在备注标注 |
| L1空间锚 | 每场景输出一次，放全局块 | 角色移动时在画面描述写明方向 |
| L2状态锁 | 全局块输出基础状态 | 有变化时写"角色A从X变为Y"；无变化不写 |
| L3道具锁 | 全局块输出基础道具/着装 | 道具变化时写"角色A放下XX/获得XX"；无变化不写 |
| L4交接帧 | 跨视频拆分时写（不变） | 同左 |
| L5光影锁 | 每场景输出一次，放全局块 | 光线变化时写明原因（灯灭/日落/法术光） |
| L6声音锁 | 每场景输出一次，放全局块 | 声音变化时写"环境音骤停"等标注 |

■ 全局模式下多场景处理
- 第一个场景的锁定信息放全局前缀块
- 后续新场景：在该场景首个分镜的标题行之后、正文之前，写该场景的[空间锚][光影锁][声音锁]
- 切回已出现过的场景：标注"场景：xxx（锁定信息见前）"
- 角色卡始终在全局块，不随场景切换重复

■ 字数节省效果
- 逐镜模式：~200字锁定标签/镜 × 30镜 = 6000字
- 全局模式：~400字全局块 + ~20字变化项/镜 × 30镜 = 1000字
- 节省约83%，释放的空间用于更丰富的动作和情绪描述

■ 自检清单适配
全局模式下，18项自检清单调整为：
- 全局块完整性检查：角色卡/空间锚/光影锁/声音锁是否完整且全局只输出一次？
- 逐镜变化项检查：有变化时是否标注了？无变化时是否省略了锁定标签（而非重复）？
- 跨场景检查：新场景是否写了新的锁定信息？切回旧场景是否标注了引用？
- 交接帧检查：跨视频拆分时首镜是否有[交接]标签？
模板C不变，仍用原18项逐镜检查。

附录：提示词结构优先级重排
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 问题
当前拼装公式中，空间和站位信息埋在"人物状态"或"画面描述"中间段。
生成模型对提示词"前重后轻"——开头权重最高，越往后越弱。
空间信息放在中间，被画质、镜头、构图等参数稀释，模型容易丢失。

■ 修改后的拼装公式（空间和道具信息前置）

全局模式（模板A/B/D）：
[全局锁定块：角色卡+空间锚+状态锁+道具锁+光影锁+声音锁+防崩锁词(可选)]
→ [画质风格前缀] → 各分镜正文（仅含变化项+画面描述+运镜+台词+音效+特效）

逐镜模式（模板C）：
[全局防崩锁词(可选)] → [空间锚]+[状态锁]+[道具锁]+[光影锁]+[声音锁] → [交接帧(如有)] →
[画质风格] → [镜头机位] → [构图画幅] → [场景环境] → [人物状态/表情] →
[动作动势] → [光影色彩] → [特效层级] → [时长台词] → [负面提示(仅模板B)]

■ 全局防崩锁词（可选·置顶）
在所有锁定标签之前，可加一句总括性防崩指令，给模型最高优先级约束：
"画面锁定：人物位置固定无偏移，肢体结构正常无崩毁，画面风格统一，无多余畸变元素"
- 适用场景：模型频繁出现肢体崩毁/人物漂移/画面畸变时启用
- 默认不启用，仅在反复生成失败时作为增强手段加入
- 通用性：所有模型通用，不限定平台
- 不计入画面描述字数限制

■ 对比

原公式（空间信息埋在中间）：
镜号+时长+运动姿态+人物状态/站位/表情+场景环境+环境反馈+
主画面描述+运镜+音效+台词+特效+生成参数+负面提示

新公式（空间信息置顶）：
[空间锚]+[状态锁]+[道具锁]+[光影锁]+[声音锁]+[交接帧] → 画质风格 → 镜头 → 构图 →
画面描述（含表情/动作）→ 光影 → 特效 → 台词 → 音效 → 负面提示(仅模板B)

■ 铁律
1. [全局防崩锁词]（如启用）必须在所有标签之前，是提示词的第一个元素
2. 模板A/B/D使用全局模式：锁定信息放全局前缀块输出一次，逐镜仅写变化项
3. 模板C使用逐镜模式：每镜强制复写全部六层锁定标签，即使无变化
4. [交接帧]仅出现在跨视频拆分后的第一镜（两种模式均如此）
5. 空间锚、状态锁、道具锁、光影锁和声音锁不计入画面描述字数限制
6. 数值坐标模式为可选增强，启用时与绝对方位词并用（不替代）
7. 全局模式下角色卡替代角色锚定串，全局输出一次；逐镜模式下角色锚定串每镜复写

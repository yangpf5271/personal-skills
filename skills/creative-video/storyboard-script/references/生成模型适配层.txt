【为什么需要这个库】
不同 AIGC 视频生成模型对提示词的长度上限、结构偏好、权重理解差异极大。
同一套分镜提示词投喂不同模型，效果可能天差地别。
加了空间锚+状态锁+道具锁后，每镜锁定信息已有80-150字，
加上画质风格50字、画面描述150字——总提示词可能超过400字。
本库提供：各模型字数预算、结构偏好、权重写法、超限截断优先级。

【核心原则：按需适配，多模型支持】
本 Skill 支持所有主流 AIGC 视频生成模型。用户告知目标模型后，按该模型的特性调整提示词。
未指定模型时，默认按标准预算（≤350字）输出，兼容多数国产模型，并询问用户使用哪个模型。

二、每镜提示词字数预算分配
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 标准预算（适配多数国产模型，总计≤350字）

[空间锚+状态锁+道具锁]    ≤80字  （锁定信息，压缩但不省略）
[画质风格]                ≤50字  （全局参数，只写差异）
[场景环境]                ≤40字  （三层景深精简版）
[人物+表情+动作]           ≤80字  （核心描述区）
[光影]                    ≤30字  （光型/光比/色温）
[特效]                    ≤30字  （无特效写"无"省字）
[台词]                    ≤20字  （计入字数铁律）
———————————————
总计：≤330字

■ 长预算（适配 Runway/Sora/Veo 等长提示词模型，总计≤600字）

[空间锚+状态锁+道具锁]    ≤100字
[画质风格]                ≤80字
[场景环境]                ≤60字
[人物+表情+动作]           ≤120字
[光影]                    ≤50字
[特效]                    ≤50字
[台词+音效]               ≤40字
[运镜]                    ≤50字
———————————————
总计：≤550字

■ 短预算（适配 Pika/SDXL 等短提示词模型，总计≤250字）

[空间锚+状态锁+道具锁]    ≤60字  （极限压缩，只留角色位置+姿态+道具）
[画质风格]                ≤40字  （只留最核心风格词）
[场景环境]                ≤30字  （一句话场景）
[人物+表情+动作]           ≤60字  （只留主体+动作+核心表情）
[光影]                    ≤20字  （只留光型+色温）
[特效]                    ≤20字  （无特效省略）
[台词]                    ≤20字
———————————————
总计：≤250字

三、超限截断优先级（当提示词超过模型预算时按此顺序砍）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 绝对不砍（最高优先级，无论如何不能删）

1. [空间锚]  —— 砍了 = 人物位置乱跳
2. [状态锁]  —— 砍了 = 背景人物忽坐忽躺
3. [道具锁]  —— 砍了 = 杯子换手/衣服开合乱跳
4. 主体动作描述 —— 砍了 = 模型不知道干什么
5. 角色身份锚定串 —— 砍了 = 角色长相变

■ 先砍（最低优先级，超限时优先删）

1. 音效描述 —— 对画面影响最小
2. 环境细节描写 —— 前景/中景/远景的细化描述
3. 光影数值 —— 只留光型+色温，删光比和具体角度
4. 色彩比例（60-30-10）—— 删掉，留主色即可
5. 特效层级描述 —— 只留"L1-L4"，删掉详细描述
6. 台词情绪标注（【读取情绪】部分）—— 只留台词本体

■ 铁律
- 空间锚+状态锁+道具锁+动作 = 永远不砍
- 砍的时候整句删，不要留半句
- 砍完后检查：主体第一句还在不在？角色锚定串还在不在？

四、各模型适配写法建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 可灵 Kling 适配建议

1. 中文描述效果优于英文，直接用中文输出
2. 运动描述权重高 → 运镜和动作描述放在画面描述前段
3. 空间锚/状态锁/道具锁用中文标签 [空间锚] [状态锁] [道具锁] 即可
4. 图生视频模式下，参考图权重 > 文字描述 → 文字描述可精简至200字
5. 对"缓慢推近""环绕运镜""从左到右"等方向性描述理解精准
6. 生成参数建议格式："8K超高清，电影级CG质感，竖屏9:16，XX风格"

■ 即梦 Jimeng 适配建议

1. 提示词尽量简洁，控制在300字以内效果最好
2. 对风格关键词敏感 → 画质风格词放在最前面（空间锚之后）
3. 过长提示词会导致"丢信息" → 严格按截断优先级压缩
4. 对"写实""胶片""电影级"等审美类词权重高
5. 空间锚可压缩为："场景：XX，角色A在左，角色B在右"
6. 道具锁可压缩为："角色A手持XX，角色B空手"

■ Vidu 适配建议

1. 提示词控制在350字以内，过长效果明显下降
2. 关键词+短句混合写法效果好，避免纯长段落
3. 角色一致性较好 → 角色锚定串可适度精简（保留核心特征词）
4. 支持参考图 → 图生视频模式下锚定串可进一步简化
5. 场景描述一句话即可，不要分层展开

■ 海螺 Hailuo 适配建议

1. 自然语言描述效果好，避免关键词堆叠
2. 运动轨迹理解强 → 运动路径用"从X到Y"明确方向
3. 情绪氛围词权重高 → 氛围描写放在画面描述中
4. 中文描述优于英文
5. 字数控制在400字以内

■ Runway Gen-3 适配建议

1. 英文输出效果远好于中文 → 空间锚/状态锁/道具锁也用英文
2. 接受长提示词（500-800字）→ 不需要大幅压缩
3. 对运镜术语理解精准 → "dolly zoom""crane shot""whip pan"直接使用
4. 结构化写法效果好 → 用逗号分隔参数，不用自然语言段落
5. 英文标签格式：[SPATIAL] [STATE] [PROPS]
6. 权重写法：(word:1.3) 格式

■ Luma Dream Machine 适配建议

1. 中等长度（300-500字）效果最佳，过长会模糊焦点
2. 英文自然语言段落优于关键词堆叠
3. 对光影描述敏感 → 光影描写可以详细一些
4. 角色锚定串用英文，保留核心外貌特征词
5. 避免过多参数化描述，用叙事性语言

■ Pika 适配建议

1. 简洁关键词效果最好，控制在300字以内
2. 对负面提示词权重高 → 负面提示词精确写（模板B专用）
3. 支持区域控制 → 可指定画面区域分别描述
4. 关键词优先于自然语言 → 空间锁/状态锁用短标签
5. 避免长段落，用逗号分隔的短句

■ Sora 适配建议

1. 叙事性描述效果好 → 用自然语言段落，不用关键词堆叠
2. 不限长度但偏好"讲故事"的方式 → 把画面描述写成完整句子
3. 对物理逻辑理解最强 → 动作因果关系描述清楚效果最好
4. 对时间顺序敏感 → 视频提示词用"first...then...finally..."结构
5. 空间锚融入叙事 → "In the hospital room, the bed is centered..."

■ Veo 3 适配建议

1. 英文自然语言段落效果好，400-700字范围最佳
2. 画面质量和物理运动理解强 → 光影和动作因果可详细描述
3. 对运镜术语理解好 → 可使用专业摄影术语
4. 角色锚定串用英文，保留完整外貌特征

■ Midjourney（分镜图）适配建议

1. 英文关键词效果最好 → 空间锚也转英文
2. 总长控制在300字以内 → 严格按截断优先级压缩
3. 画面审美权重最高 → 构图/光影/色彩描述放在前段
4. 参数控制：--ar 16:9 或 --ar 9:16，--s 750（风格化），--niji（二次元）
5. 权重写法：keyword::1.3 或 keyword::
6. 负面提示用 --no 参数，不用单独列表

■ Flux（分镜图）适配建议

1. 自然语言段落效果好 → 直接用中文完整句子
2. 长描述不丢信息 → 可以写400-500字
3. 写实类效果强 → "photorealistic""documentary""8K"等词权重高
4. 空间锚/状态锁/道具锁用中文标签即可

■ SDXL（分镜图）适配建议

1. 关键词权重格式效果最好 → 用 (keyword:1.3) 控制权重
2. 总长控制在200字以内 → 极限压缩
3. 适合LoRA叠加 → 角色锚定串可用触发词替代
4. 过短抓不住特征，过长会冲突 → 找平衡点
5. 负面提示词必须写 → 手部/变形/多余肢体等

【核心认知：图生视频 ≠ 纯文生视频】

多数主流模型（可灵/即梦/Runway/LibTV/Vidu等）都支持图生视频模式。
图生视频模式下，参考图权重 > 文字描述，连续性主要靠图片保证。

★ 这意味着：我们建的[空间锚][状态锁][道具锁]在图生视频模式下是【辅助手段】，
  【主要连续性靠参考图系统】——文字锁用于补充图片无法表达的信息（姿态/道具细节/情绪）。

■ 图生视频模式下的锁定体系调整

当用户使用图生视频模式时（任何模型），提示词输出策略调整：

1. 【角色锚定串】→ 简化为参考图引用
   - 完整锚定串格式和规则详见 references/空间连续性控制库.txt「角色锚定串规范」
   - 不再每镜复写完整锚定串（50+字外貌描述）
   - 改为：角色名【参考图1】+ 当前着装/状态差异
   - 节省的字数用于动作描述
   - 适用模型：可灵/即梦/Runway/Vidu/LibTV 等所有支持图生视频的模型

2. 【空间锚】→ 保留，但配合参考图
   - 文字写场景布局（让模型理解角色站位关系）
   - 跨视频时：前段末帧截图→作为下一段生成的参考图
   - 文字空间锚用于补充参考图无法表达的"谁在左谁在右"

3. 【状态锁】→ 保留（图生视频最需要补充的锁）
   - 参考图只能锁定"长什么样"，锁不了"在做什么动作"
   - 每镜仍需写：角色A=姿态，角色B=画外不动
   - 尤其重要：多角色场景，参考图可能只锁了主角，配角靠状态锁

4. 【道具锁】→ 保留，简化
   - 道具可被参考图覆盖时省略（如角色手持的物品在参考图中已有）
   - 道具状态变化时必须写（如"前襟湿了""发箍歪了"——参考图不覆盖变化）

5. 【交接帧】→ 用参考图替代
   - 纯文生视频：[交接]前段镜N末帧：角色位置+姿态
   - 图生视频：取前段末帧截图→作为下一段参考图→文字只补充姿态变化

■ LibTV Star Video 2.0 结构化提示词写法

Star Video 2.0 支持结构化长提示词，按以下分块组织：

-风格
[画质风格词，如：硬派国风厚重苍凉写实CG，8K虚幻引擎5 PBR渲染]

-人物
[角色外貌+着装+神态，配合@图片素材引用]
如：女孩【图片1】身穿红色嫁衣，头戴金色凤冠，神情虔诚

-道具
[道具描述+一致性要求]
如：银币中等大小，金属质感，分裂后所有银币与原始银币保持相同外观

-环境
[场景环境+氛围]
如：夜晚河边步道，石质地面，柔和路灯光，神秘浪漫暗色系

-时间线（Star Video 2.0 核心优势）
0:00–0:03 [第一段时间线的画面描述+动作]
0:03–0:06 [第二段时间线的画面描述+动作]
0:06–0:10 [第三段...]
0:10–0:15 [最后一段...]

★ 时间线写法是 Star Video 2.0 区别于其他模型的最大优势——
  可以逐秒描述动作推进，模型理解极精准。
★ 其他模型不支持时间线分块写法，仍用标准预算格式。


■ 图生视频跨集连续性标准流程（通用）

适用于所有支持图生视频的模型：

1. 生成/上传主角的参考图（不同角度/表情各1张）
2. 将参考图作为图生视频的输入
3. 第1段视频生成后，截取末帧画面
4. 将末帧截图作为第2段视频生成的参考图
5. 第2段提示词中用参考图引用 + 文字补充姿态变化
6. 重要场景/道具截图也作为后续生成的参考图

★ LibTV 画布工作流：截图→连线到新视频节点（自动化）
★ 其他模型：手动保存截图→下次生成时手动上传参考图


■ LibTV 提示词万能衔接句（仅限 Star Video 2.0）

Star Video 2.0 支持在分镜提示词末尾加一句"万能提示"，
让模型把多个画面理解为同一世界的不同瞬间：

> "将视觉序列制作成一段连贯的、完整的全画面的电影式视频。
>  将所有源画面都视为一个统一、连贯的世界中的不同瞬间。
>  整个序列应给人的感觉像是一个高质量的商业广告，而非一系列场景的拼接组合。"

适用于：多镜拼接成一条完整视频时，放在最后一段提示词末尾。
★ 其他模型不支持此衔接句。


■ LibTV Star Video 2.0 预算分配（结构化格式）

总计：500-1000+字（不需要压缩）

-风格         ≤80字
-人物         ≤150字（含@图片素材引用+着装+神态）
-道具         ≤80字（含一致性要求）
-环境         ≤100字
-时间线       ≤300-500字（逐秒/逐段描述，核心区）
-空间锚       ≤60字（补充参考图无法表达的站位关系）
-状态锁       ≤60字（补充参考图无法表达的动作姿态）
-台词         ≤80字（含角色名+语气标注）

★ Star Video 2.0 不需要写：运镜（模型自动处理）、负面提示词（自带安全过滤）
★ Star Video 2.0 自动生成环境音，音效设计字段可省略
★ 其他模型仍需完整音效设计字段（环境音+动作音两栏）


■ LibTV Star Video 2.0 + Seedance 2.0 组合工作流

推荐策略（兼顾质量和连续性）：

1. 用 Star Video 2.0 快速出完整成片（多镜叙事≤15s）
2. 对不满意的单镜，切换到 Seedance 2.0 精细重做
3. 重做时：用 Star Video 2.0 的对应帧截图 → 连线到 Seedance 2.0 节点 → 写单镜精细提示词
4. 单镜提示词用标准预算（≤350字），保留[空间锚][状态锁][道具锁]

四-C、各模型画质触发词速查（通用·可选）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 作用
不同模型对不同画质关键词的响应权重不同。在画质风格段开头加入对应触发词，
可以拉高该模型的生成画质下限。触发词不是必选——是增强手段。

■ 通用基线触发词（所有模型适用）
"8K超清，电影级质感，细节丰富"
→ 不知道用什么模型时，先用这组不会出错

■ 各模型偏好触发词

| 模型 | 推荐触发词 | 说明 |
|------|-----------|------|
| 可灵 Kling | 8K超高清，电影级CG质感，纪实风格 | 对"纪实/CG"类质感词响应强 |
| 即梦 Jimeng | 8K超清，电影级光影，漫剧渲染质感，细节拉满 | 对"光影/渲染质感"敏感，偏简洁 |
| Vidu | 超高清，电影质感，细节精致 | 过长触发词会降效，保持精简 |
| 海螺 Hailuo | 8K，电影级，沉浸感 | 对氛围/沉浸类词权重高 |
| LibTV | 知识库-视频风格.txt SECTION:H的7模板前缀 | LibTV用前缀模板，不用单独触发词 |
| Runway/Veo | cinematic, 8K, highly detailed | 英文模型用英文触发词 |
| Sora | cinematic quality, ultra-detailed | 叙事性描述优先，触发词放句首 |

■ 用法
- 放在画质风格段的最开头，锁定标签之后
- 与知识库-视频风格.txt SECTION:H的模板前缀不冲突——触发词管画质下限，前缀管渲染风格
- 字数计入提示词总预算（通常15-25字）
- 模型频繁出低画质/模糊/塑料感时启用，画面正常时非必须

五、模型选择决策树
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

用户未指定模型时，询问用户使用哪个模型。
如用户需要推荐，按以下规则按需推荐：

1. 国产漫剧/短剧（竖屏9:16，单镜生成）→ 可灵 Kling
   - 中文角色名多 → 中文优化好
   - 空间关系复杂 → 空间理解强
   - 支持图生视频 → 交接帧可用参考图

2. 纪实/胶片风格 → 即梦 Jimeng
   - 审美感强 → 画面质感好
   - 简洁提示词 → 不容易过载

3. 角色一致性要求高 → Vidu / 可灵图生视频
   - 参考图能力强 → 角色不容易变
   - 适合需要跨镜角色一致的场景

4. 海外项目/英文内容 → Runway Gen-3 / Veo 3
   - 长提示词友好 → 不需要大幅压缩
   - 运镜术语精准 → 专业分镜效果好

5. 需要物理逻辑复杂（打斗/碰撞/流体）→ Sora
   - 物理理解最强 → 动作因果准确
   - 叙事性描述 → 适合复杂动作链

6. 简洁关键词风格 → Pika
   - 关键词优先 → 适合快速生成
   - 负面提示词权重高 → 精确控制

7. 多镜叙事直出（需要一次生成含多镜头/对白/环境音的完整成片）→ LibTV Star Video 2.0
   - 可直出完整成片（含分镜/转场/对白/环境音）
   - 画布工作流解决跨集连续性（图片参考+截图传递）
   - 理解时间线逐秒描述，动作精准
   - 配合 Seedance 2.0 可对单镜精细化
   - 适合：有连续剧情、多角色、多场景的短剧

8. 分镜图/关键帧生成 → Midjourney V6
   - 审美和构图最强 → 分镜图质量最高
   - 参数控制灵活 → 比例/风格化/模型版本可控

★ 用户明确指定模型时，直接按该模型的适配建议输出提示词。
★ 用户使用图生视频模式时（任何模型），角色锚定串可简化为参考图引用。
★ 用户使用 LibTV Star Video 2.0 时，改用结构化分块格式（风格/人物/道具/环境/时间线）。

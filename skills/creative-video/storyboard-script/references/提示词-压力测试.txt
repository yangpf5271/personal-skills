# 提示词压力测试机制
# Prompt Stress Test Mechanism
# 版本：V1.0

════════════════════════════════════════════════════════════
【概述】
════════════════════════════════════════════════════════════

在步骤7输出分镜提示词后、步骤8检查之前，对每条视频提示词（或图像提示词）
执行字数预算压力测试。分为三档：

  🟢 绿色 = 安全（≤预算80%）：正常通过，无需处理
  🟡 黄色 = 警告（80%-100%）：逼近上限，建议检查是否有冗余词
  🔴 红色 = 超限已压缩（>100%）：已按截断优先级自动压缩，需标注被砍字段

════════════════════════════════════════════════════════════
【压力计字段映射】
════════════════════════════════════════════════════════════

以下字段为提示词字数预算的"受检字段"（按模板区分）：

  模板B：视频提示词（如有）+ 生成参数（如有加载库要求的完整提示词）
  模板C：视频提示词（17必填中的最后一项）
  模板A：不适用（模板A无提示词输出）

════════════════════════════════════════════════════════════
【截断优先级（压缩顺序，从先砍到后砍）】
════════════════════════════════════════════════════════════

  优先级 1（最先砍）：音效描述、环境细节文字
  优先级 2            ：光影数值（色温/光比/ISO等数字参数）
  优先级 3            ：色彩比例（如"暖色60%+冷色40%"）
  优先级 4            ：特效细节（粒子数量/扩散范围等量化描述）
  优先级 5            ：台词情绪标注（读取情绪标签）
  优先级 6（最后砍）：画面补充细节（前景/中景/远景分层）

  以下字段绝对不砍（保持完整）：
    - 空间锚 / 空间锚定串
    - 状态锁 / 人物状态锁
    - 道具锁
    - 动作描述 / 主动作
    - 角色锚定串 / 角色名称
    - 主画面描述（核心叙事100字保底）

════════════════════════════════════════════════════════════
【红色状态标注格式】
════════════════════════════════════════════════════════════

当某镜提示词超限且已压缩后，在该镜末尾（视频提示词字段下方）添加：

  ⚠️ 压力告警—本镜提示词 {原始字数}字 → 已压缩至{当前字数}字（预算{预算字数}字）
  以下字段因超预算被压缩：[音效]已砍 / [环境细节]已砍 / [光影数值]已砍 / [色彩比例]已砍

  📋 用户选择：
  [1] 接受压缩版（默认，当前输出即压缩版）
  [2] 升级模型 → 重新以 {更大预算模型} 字数预算输出本镜提示词
  [3] 拆分镜头 → 将本镜拆为 N 个短镜，每个独立预算内

════════════════════════════════════════════════════════════
【压力计输出位置】
════════════════════════════════════════════════════════════

  单镜压力计：紧接在每镜的视频提示词字段之后（仅红色镜显示）
  全局压力计：在所有分镜卡片输出完毕后，集中列出

  全局压力计格式：

  ═══════════════════════════════════
  📊 提示词压力·全局报告
  ═══════════════════════════════════
  模型：可灵 (预算500字)  |  模板：B  |  总镜头数：35
  🟢 安全镜：28  (≤400字)
  🟡 预警镜：5   (401-500字)
  🔴 超限镜：2   (镜18已压缩/镜27已压缩)
  ═══════════════════════════════════

════════════════════════════════════════════════════════════
【与步骤7字数字算的关系】
════════════════════════════════════════════════════════════

  步骤7 负责：预算分配 + 模型适配策略选择
  步骤7.5 负责：实际字数校验 + 压力定级 + 标注+选项呈现

  两者不冲突：步骤7定策略，步骤7.5做验证。

════════════════════════════════════════════════════════════
【与 SKILL 主流程的联动】
════════════════════════════════════════════════════════════

  SKILL 步骤7.5 将调用本参考库的两套机制：
    1. 读取本库的截断优先级和压力计输出格式
    2. 执行 scripts/validate_shot.py 做逐镜字数检测（检测12）

  红色镜的处理逻辑：
    - 默认：输出压缩版的视频提示词，附压力告警 + 用户选项
    - 用户选[2]升级模型：回到步骤7，按新模型预算重写该镜提示词 → 再压测
    - 用户选[3]拆分镜头：回到步骤2，将该镜拆为2-3个短镜 → 全量重跑步骤3.5-7.5

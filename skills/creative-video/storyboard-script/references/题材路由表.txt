# 题材路由表
# 作用：步骤1确认风格和题材后，按本表确定步骤6需要加载哪些专属库。
# 步骤1.5（感性意图解码）在题材路由之后执行——用户感性表达("特效拉满"等)产
# 生的参数偏好转译会影响专属库内部的SECTION选择（如"特效拉满"→优先加载动作库SECTION:07+08），
# 但不会改变题材簇本身的选择。意图解码表详见 references/感性意图解码表.txt。
# 通用库在步骤3-8始终调用，不在本表重复列出。
# 专属库按题材簇选择性加载，不相关的库不加载，减少上下文噪音。
#
# 【索引检索模式】所有标注"先Read索引"的大文件（知识库-动作特效.txt 83KB、知识库-运镜整合.txt 35KB）
# 已内置前置关键词索引。加载流程：Read文件头25行索引表 → 匹配关键词 → Grep定位SECTION标记 → Read仅加载目标段落。
# 禁止全文加载这两个文件。单次最多加载3个段落（token预算<80K时）或2个段落（≥80K时）。

四、跨簇组合规则
═══════════════════════════════════════════════════

当一部作品混合多个题材簇时（如"古装+悬疑"="古风推理"）：
1. 以主题材簇为基准加载必选库
2. 副题材簇的必选库降级为可选库，按剧情实际需要加载
3. 副题材簇的可选库保持可选

示例：
- "古装悬疑" → 主簇B（古装武侠），副簇E（悬疑）的运镜库已在主簇必选，
  副簇的表情大全SECTION:B升级为必选（悬疑需要恐惧/震惊表情）
- "仙侠+喜剧" → 主簇C（仙侠），副簇G（喜剧）的表情大全SECTION:B已在主簇必选
- "都市+动作" → 主簇A（现代都市），运镜库已在主簇必选（SECTION:A+E），副簇D补充加载运镜库SECTION:D打斗专项 + 三个动作库按打斗场面需要加载

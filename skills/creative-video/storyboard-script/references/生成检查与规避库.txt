SECTION:A-可生成性检查

# 分镜可拍性 可生成性检查库
## references/分镜可拍性可生成性检查库.txt

本库为分镜交付前最后一道闸，一票否决。与视觉分层库、台词系统、空间连续性控制库并列调用。

> 核心认知：**模型一次只能画好"一个瞬间"。** 文字分镜可以行云流水，但生成时一镜塞两个动作=必崩。

---

## 一、单动作铁律（一票否决项）

| 规则 | 错误写法 | 正确拆法 |
|---|---|---|
| 单镜头只表达**一个主要动作** | "苏辰拔剑、跃起、劈碎巨石"（3动作1镜） | 拆3镜：拔剑起手→跃起悬空→劈碎命中 |
| 静态画面不塞连续动作 | "他边跑边回头喊人" | 图像只取"回头瞬间"1帧，奔跑交给动态模糊/残影暗示 |
| 动作链必须切成"关键帧链" | 一场打斗1镜到底 | 按"起手→碰撞→结果"逐帧分镜（见第九条） |

**自检口诀**：读一遍画面描述，数动词——**主动词>1，拆镜**。（"掐诀"带"金光炸开"是允许的动作+特效，不算双动作；"掐诀并转身"算双动作，拆。）

---

## 二、人物数量控制

| 画幅 | 清晰主体上限 | 处理规则 |
|---|---|---|
| 竖屏9:16 | **2人** | 第3人起做虚化背景/剪影/背影 |
| 横屏16:9 | **3-4人** | 超出者降层：虚化→剪影→远景色块 |
| 群像场面 | 前景主体≤2 + 背景人群 | 人群写"虚化人群剪影"，禁逐人描述 |

**避坑**："大殿上数十名弟子表情各异地议论"=必崩（模型会给每张脸崩坏特写）。改写：`前景2人主体清晰，背景弟子群虚化降饱和30%做剪影`。

---

## 三、同屏多人站位规则

| 规则 | 写法 |
|---|---|
| 站位必须写成**平面布局** | "苏辰画面左1/3，长老右1/3，面对面相距2米"（禁只写"两人对峙"让模型猜） |
| 纵深错开 | 多人禁站同一水平线，写"前1后2错位站位" |
| 朝向明确 | 每人写面朝方向（"长老侧身45°面向镜头"） |
| 高度差数值化 | "长老居高俯视（站位高1台阶）"，制造权力关系 |

---

## 四、避免复杂遮挡

| 高危写法（禁） | 安全改写 |
|---|---|
| "手挡在脸前做复杂手势" | 手势放脸侧/胸前，面部无遮挡 |
| "两人在柱后纠缠打斗" | 拉柱为前景虚化框，人物在开阔区 |
| "隔着人群对视" | 人群中间让出通道（引导线构图），视线无遮挡 |
| 前景遮挡＞15%画面 | 前景压到5-15%且写明"虚化60%+避开面部区" |

**铁律**：**面部与关键道具是全画面禁遮挡区**，任何前景元素不得覆盖。

---

## 五、台词与画面匹配检查

| 校验项 | 标准 |
|---|---|
| 台词时长≤镜头时长 | 按字数铁律反查：3秒镜塞35字=超配，拆镜或删字 |
| 说话人必须在画面内 or 标注画外音 | 不标注=模型随机分配口型 |
| 无口型独白必须标注 | 漏标"无口型"=模型给人物配上蠕动嘴唇 |
| 一镜最多1个说话人 | 对话回合=正反打两镜，禁一镜两人交替说话 |

---

## 六、特效密度控制

| 规则 | 量化 |
|---|---|
| 单镜特效系统≤1套 | "火凤+冰锥+雷链同屏"=崩；拆3镜各放一套 |
| 光效层级≤4层、总占比≤40% | 沿用L1-L4规范，超了砍L4 |
| 特效与动作同框时，主体仍是人 | 人物占比≥25%，禁"满屏特效找不着人" |
| 环境动态≤2种 | "飘雪+落叶+烟雾+飞花"=杂乱；保留2种最有叙事价值的 |

---

## 七、主体前置与分层检查

**交付前逐项打勾**：
- [ ] 主体（人/道具）在画面描述**第一句**出现，而非埋在环境描写后
- [ ] 前景/中景/远景三层写全，主体在中景且锐度最高
- [ ] 场景描写与角色描写**分段书写**，不搅在一个长句里
- [ ] 背景元素总数≤5类，超出删远景

---

## 八、近景表情清晰规则

| 规则 | 写法 |
|---|---|
| 颜艺/情绪帧必须给足面部资源 | 面部占比≥50%+面部提亮1-1.5档+锐度最高 |
| 表情描述≤2个复合项 | "震惊+狂喜+心虚+愤怒"四合一=模型随机抽签；取主情绪+1辅（"震惊中带狂喜"✓） |
| 特写镜禁配大动作 | 大特写里"挥手打斗"=裁切崩坏；特写只写微表情+眼神 |
| 眼神方向写明 | "视线锁定画面右上方"（给模型注视锚点） |

---

## 九、动作戏标准拆镜法

### 9-1 打斗三连拆（每段独立成镜）

```
【起手镜】蓄力姿态定格：重心下沉/武器后拉/特效开始聚集（1-1.5秒）
【碰撞镜】命中瞬间：冲击点+形变+气浪+动势线收束（0.5-1秒，全画面最亮帧）
【结果镜】余波呈现：烟尘扩散/对手飞出/地面龟裂/主角收势（1-2秒）
```

### 9-2 法术四连拆

```
【蓄力镜】能量汇聚：L1核心起光，环境变暗衬托（1.5-2秒）
【释放镜】法术离手：L2主光效+动势线甩出（1秒）
【命中镜】落点爆发：L2-L3满功率+受力冲击（0.5-1秒）
【余波镜】L4粒子飘散+环境损伤+人物反应帧（1.5-2秒）
```

**铁律**：连贯动作靠**剪辑节奏**产生，不靠单镜塞满。文字上"行云流水的一剑"=画面上3-4个短镜快切。

---

## 十、运镜复杂度控制

| 规则 | 标准 |
|---|---|
| 单镜主运镜线=1条 | 复合最多2动作叠加（推+摇✓ 推拉摇环绕✗） |
| 轨迹必须数值化 | "环绕180°、半径3米、中速"——不数值化=模型自由发挥 |
| 非常规运镜限位 | 希区柯克/子弹时间/Z字穿梭全剧单集≤2次，且只在反转/绝杀帧 |
| 手持晃动仅配对应情绪 | 慌乱/追逐专用，文戏用=晕 |

---

## 十一、图像 Prompt vs 视频 Prompt 分写法（关键区分）

| 维度 | 图像 Prompt | 视频 Prompt |
|---|---|---|
| 动作 | 只写**瞬间姿态**（1个定格帧） | 写**运动过程**（从X到Y的变化轨迹） |
| 时间词 | 禁"然后/接着/之后" | 必须有：起幅→过程→落幅 |
| 运镜 | 不写运镜，写构图与机位 | 运镜轨迹是核心参数，必写方向+速度 |
| 表情 | 写最强一帧的表情峰值 | 写表情变化（"从冷笑到瞳孔地震"） |
| 特效 | 写当前帧状态 | 写特效演化（"金光从掌心扩散至全身"） |
| 台词 | 不写（图像无音频） | 写台词时长+口型匹配 |
| 典型错误 | 把"他转身拔剑冲出去"塞进图像 | 只写"持剑站立"浪费视频能力 |

**一镜双写模板**：
```
图像版：苏辰侧身回眸瞬间，嘴角上扬，金剑芒凝于剑尖（定格峰值帧）
视频版：起幅：苏辰背对镜头→甩袖转身回眸（0.8秒）→落幅：嘴角上扬定格，
        剑尖金芒由暗转亮，环绕运镜右旋30°慢速
```

# AI生成失败规避库（漫剧 AIGC 专版）
## references/AI生成失败规避库.txt

> 每条规则 = 失败现象（崩成什么样）→ 根因（为什么崩）→ 规避写法（怎么写不崩）→ 正反例。
> 使用时机：分镜写完过可生成性自检闸（references/分镜可拍性可生成性检查库.txt）之后、提交生成之前，逐镜扫一遍本库；
> 生成翻车之后，用文末【失败速查表】对症下刀，禁止无脑重roll。

---

## 一、人物数量类失败

### 1.1 一镜清晰人物 ≤ 2-3 个
**失败现象**：第3个人开始脸崩成路人、五官融化漂移、A的发型长B头上、双人特征互换（"换脸"）。
**根因**：模型细节配额有限，清晰刻画的人物超过2-3个后配额不够分，特征互相串味。
**规避写法**：竖屏清晰主体≤2人，横屏≤3-4人；第三人起强制降层（虚化→剪影→色块）。
```
× 宴会厅中知微冷笑，明珠震惊，沈建国铁青，周雅琴捂嘴，四人表情各异
√ 前景知微与明珠双人对峙（清晰），背景沈建国夫妇虚化为两团剪影轮廓
```

### 1.2 群像必须虚化或剪影
**失败现象**：群像人人有脸 = 满屏崩脸；更常见的是**复制脸**——同一张脸出现十几次，恐怖谷效应。
**根因**：模型批量生成人脸时会复用特征直接复制粘贴。
**规避写法**：群像三选一——①整体虚化70%+ ②逆光剪影 ③远景色块；用"数量词+集体动态"替代个体描述，禁止逐个写群演表情。
```
× 二十个宾客各自露出震惊的表情，有人捂嘴有人瞪眼有人后退
√ 背景宾客群像整体虚化70%，轮廓攒动，三四部手机举起点亮反光
```

---

## 二、遮挡类失败

### 2.1 法阵/特效不遮脸（漫剧第一翻车王）
**失败现象**：法阵浮在脸前 = 符文纹理焊在脸上、五官被发光图层吃掉、脸变成法阵的一部分。
**根因**：发光特效会被模型当作最高优先级渲染层，盖在哪、哪的结构就被光纹替换。
**规避写法**：法阵位置锁死三个安全区——**脚下地面 / 身后背景 / 掌心前方（与面部错层）**；
必须加一句保险："面部干净，无符文投影，无遮挡"。
```
× 她面前浮现金色法阵，符文流转映在她脸上
√ 金色法阵在她脚下地面展开，环径两米，符文贴地旋转；
  面部干净无光影污染，仅下颚线被地光微微勾边
```

### 2.2 面部与关键道具=绝对禁遮区
失败重灾区清单：手捂脸说话 / 隔人群对视 / 柱后纠缠 / 前景枝叶扫过面部 / 发丝糊脸的表情特写。
规避：前景遮挡占画面5-15%且虚化60%+，坐标避开面部区（竖屏上1/3线）。

---

## 三、动作复杂度类失败

### 3.1 手部动作不要太复杂
**失败现象**：复杂手势 = 六指琴魔、手指融化粘连成蹼、结印结成一坨肉、筷子手。
**根因**：手部是扩散模型公认弱项，描述越复杂崩得越离谱——动作复杂度与崩坏率成正比。
**规避写法·手部动作降级表**：
| 你想写的 | 降级为（安全词库） |
|---|---|
| 十指翻飞结法印 | 右手并指前点，指尖凝聚一点金光 |
| 双手快速变换结诀 | 双手合十，缓慢拉开，掌间光丝牵连 |
| 弹指射出银针 | 两指捻针抬至肩高，定格蓄势 |
| 复杂持剑花式 | 右手握剑柄，剑尖斜指地面 |
**安全词库**：攥拳 / 摊掌 / 并指前点 / 单手上抬 / 按剑柄 / 托杯 / 负手
**高危禁区**：双手结印 / 弹指 / 比心 / OK / "十指翻飞" / 任何需要精确指法的描述

### 3.2 武器不要穿模
**失败现象**：剑穿过手腕、刀柄和手长成一体、兵器插进自己身体、一把剑两头都是尖。
**根因**：模型不理解"持握"这一物理关系，"手+兵器"是穿模重灾区。
**规避写法**：持握关系三要素写死——**哪只手+握哪个部位+兵器指向哪**；兵器运动轨迹单镜仅一条；禁"剑绕身旋转""双剑交叉格挡"类复合空间关系。
```
× 长剑在她周身翻飞环绕，剑光织成密网
√ 她右手握剑柄中段，剑身与小臂成一条直线，剑尖斜指左下方地面
```

### 3.3 打斗禁止"连续过招十几回合"
**失败现象**：模型把十几回合压缩进几秒 = 双方手臂抽搐乱挥、武器瞬移、人体拧成麻花、两个人渲染成一个人。
**根因**：视频模型单镜头只承载1-2秒有效动作，"十几回合"超出时间容量，模型只能随机抽帧乱拼。
**规避写法**：回合→关键帧拆镜（三连拆：起手→碰撞→结果）；"过了很多招"的感觉靠**剪辑密度**制造，不靠单镜塞。
```
× 两人你来我往激战十几回合，剑光如雨爪影重重
√ 拆三镜：
  镜A：甲方挥剑下劈（起手定格1s）
  镜B：双剑碰撞，火花放射（命中帧0.5s，全场最亮）
  镜C：乙方虎口震裂倒退三步（结果帧1.5s）
```

### 3.4 一镜只表达一个明确动作（动词计数法）
**失败现象**：塞两个动作 = 模型渲染出两动作的"中间态"，人物抽搐、姿势不伦不类；或随机丢弃一个。
**规避写法**：数主动词，>1拆镜。许可组合=动作+特效（"掐诀+金光炸开"✅）；禁止组合=动作+动作（"掐诀并转身"×）。
例外豁免：信息帧（闪回/字幕帧）与反应帧（纯表情）不计主动作，但单集信息帧≤5个。

---

## 四、动态物理类失败

### 4.1 柔性元素禁止"同向爆炸"（漫剧特有高发）
**失败现象**：长发、衣袖、飘带、灵力光带被同一阵风往同一方向吹 = 糊成一片彩色面条、发丝与飘带焊死、光带缠住头发分不清彼此。
**根因**：多个动态柔性元素同向同速时，模型会把它们合并渲染成一团连续色块。
**规避写法·三向分离法则**：
- 动态元素≤2种剧烈，其余交给重力（静态垂坠）
- 必须多动态时，方向强制错开：发丝向后 / 衣袖向下垂坠 / 灵力向上盘升
```
× 她长发、衣袖、飘带、灵力全部向后狂舞，衣袂翻飞
√ 发丝向后扬起（主动态）；衣袖因抬臂自然垂坠（重力静态）；
  灵力光带自掌心向上盘升（反向）——三层方向互不重叠
```

### 4.2 受力反馈单一明确
失败现象：写"气浪炸开、碎石飞溅、地面龟裂、烟尘冲天、衣发狂舞"全堆一镜 = 画面糊成粥。
规避：命中帧只选**1种主反馈+1种次反馈**（如：环形气浪+衣发炸起），其余删掉。

---

## 五、景别冲突类失败

### 5.1 近景不要同时写大场景奇观
**失败现象**：近景人脸+背景万剑归宗 = 细节配额打架，脸崩了、奇观也糊了，双输。
**根因**：像素配额守恒——近景人物要吃掉大部分细节预算，大奇观也要吃，互相挤占。
**规避写法·景别与奇观绑定表**：
| 景别 | 奇观处理 |
|---|---|
| ECU/CU/MCU | 奇观降级为背景光雾、粒子、虚化光斑 |
| MS/FS | 奇观可现形，但只能一种系统 |
| LS/ELS | 大奇观主场，人物占比≤15%任其小 |
```
× 近景她冷笑着，身后万剑悬空遮天蔽日
√ 方案A（保近景）：近景她冷笑，身后剑阵虚化成一片金色光雾
√ 方案B（保奇观）：切ELS——万剑悬空遮天，她占比8%立于剑雨中心
```

## 六、提示词语言类失败

### 6.1 视频提示词：静态构图词占比过高
**失败现象**：堆"三分法构图、黄金分割、对称美学、留白意境" = 运动被压制，人物像PPT缓慢平移、运镜失灵、动作僵住。
**根因**：静态构图词吸走模型的"画面质量注意力"，挤压运动描述的权重——**构图词越多，动得越差**。
**规避写法·视频版权重分配**：运动类词（动作+运镜+时间词）≥60%；构图词只保留**机位+焦点**两个，美学形容词全删。
```
× 视频版：三分法构图，黄金分割，对称美学，意境留白，她从左走到右
√ 视频版：跟镜平移，她从画面左侧行至右侧，步速中速，
  发丝随步伐轻晃，全程3秒，落幅定格于右1/3处
```

### 6.2 图像提示词：时间连续动作
**失败现象**：写"她先抬手然后转身接着挥剑" = 模型没有时间轴，把所有步骤拍扁进同一帧，产出三头六臂的中间态。
**根因**：图像模型眼里没有"先/然后/接着"，所有词都是"此刻"。
**规避写法**：图像版只写**峰值帧**——从动作链里选最具识别度的一帧定格；时间连接词全部删除。
```
× 图像版：她先抬手结印，然后灵力汇聚掌心，接着一掌拍出
√ 图像版：她右掌前推至尽头定格，掌心金光呈放射状爆发，
  衣袖被气流整体向后压贴，碎石离地悬浮
```

### 6.3 一镜双写分工铁律（与可生成性检查库呼应）
| 维度 | 图像版 | 视频版 |
|---|---|---|
| 动作 | 只写定格峰值姿态 | 写起幅→过程(秒数)→落幅 |
| 时间词 | 零容忍 | 必须有 |
| 运镜 | 禁写，只写机位构图 | 必写方向+轨迹+速度 |
| 表情 | 写峰值一帧 | 写渐变（"从冷笑到瞳孔收缩"） |
| 特效 | 写当前帧状态 | 写演化（"金光自掌心扩散至全身"） |

## 七、负面提示词类失败

### 7.1 禁止每镜无脑复制一大串
**失败现象**：
- **自我打架**：正向写了"动态模糊"，负面里躺着"模糊"→模型随机取舍，产出不可控
- **误杀**：手部特写镜带着高权重"手部畸形"→模型干脆把手裁出画面
- **压平表演**：颜艺帧带着"五官扭曲"→夸张表情被负面词拉回面瘫
**根因**：负面词与正向词冲突时不分对错，按权重随机生效。
**规避写法·负面词三层架构**：
```
【恒定层】（全集不动，5-8个）：
  低分辨率/噪点/水印/文字/logo/压缩痕迹/多人物复制脸
【场景适配层】（按镜型切换，3-5个）：
  打戏镜→肢体穿插/武器变形/关节错误
  夜景镜→死黑/欠曝/光斑糊团
  群像镜→复制脸/千人一面/面部融化
  手部镜→多手指/缺手指/手指粘连（注意与正向冲突时降权）
【本镜排除层】（0-2个，特殊声明）：
  颜艺帧→删除"五官扭曲"，加写"本镜允许夸张表情变形"
  动态模糊帧→删除"模糊"，加写"本镜允许运动方向动态模糊"
```
**冲突自查铁律**：正向写了什么，负面就不能禁什么——提交前双向扫一遍。

## 八、角色一致性类失败

### 8.1 跨镜换脸/漂移
**失败现象**：第二镜脸变了、瞳色发色漂移、年纪忽大忽小。
**规避**：锚定串每镜原样复写一字不改（完整格式和规则见 references/空间连续性控制库.txt「角色锚定串规范」）；全局参数定义代号，提交生成时必须展开全串。

### 8.2 双人同框串色串特征
**失败现象**：A的裙子颜色跑到B身上、发型互换、配饰瞬移。
**根因**：模型把"画面里存在的特征"随机分配给"画面里的人"。
**规避**：①主配角配色色相间隔≥90°（拉开即防串）；②双人镜必写空间锁——"A画面左1/3，B画面右1/3"；③特征词紧跟人名，不孤立堆在句尾。

---

## 九、运镜类失败

### 9.1 运镜幅度过大崩坏
**失败现象**：360°环绕=转到背面脸换了个人；急速推拉=糊成流光；复杂轨迹=背景漂移成另一个场景。
**规避**：环绕≤180°且标明半程；推拉速度三档（缓/中/急）选档写死；希区柯克变焦、子弹时间等非常规运镜单集≤2次且仅用于反转/绝杀帧；复合运镜≤2个动作叠加。

---

## 十、画面内文字类失败

**失败现象**：招牌、横幅、牌匾、圣旨上的字 = 乱码鬼画符、似汉字非汉字。
**规避**：①能不写就不写，文字信息改用字幕/旁白承载；②必须出现时给**确切文字内容**+字数越少越好（≤6字存活率高）；③重要文字（如"断亲协议"标题）接受乱码风险，方案是画面留白后期贴字。

## 附2｜失败重试SOP（崩了按此降级，禁止原样重roll）
```
第1刀：砍动作复杂度（复杂手势→安全词库；多动作→单动作）
第2刀：砍人物数量（3人→2人→1人+剪影）
第3刀：砍特效层级（4层→2层；占比40%→20%）
第4刀：拆镜（一镜装不下就两镜，别硬塞）
第5刀：换景别（近景崩→退中景；奇观崩→虚化或切ELS）
五刀砍完仍崩：该镜判定为"当前模型能力边界"，改写替代方案
（例：正面对打改剪影对打、结印改发光道具、文字改后期贴）
```

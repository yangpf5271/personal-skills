══════════ SECTION:A-原理 ══════════
为什么要处理版权词
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 问题
AI视频/图像生成模型（可灵/即梦/LibTV/Runway/Vidu/海螺等）内置安全过滤机制，
会检测提示词中的版权IP词汇。检测到后有两种后果：
1. 直接拦截——提示词被拒，不生成任何内容
2. 软性降质——生成内容但质量明显下降（模糊/变形/内容偏离）

常见触发类型：
- 角色真名："宇智波斑""漩涡鸣人""路飞""炭治郎"等
- 术法/能力名："写轮眼""火遁""橡胶果实""呼吸法"等
- 组织/地点名："木叶村""海军本部""鬼杀队"等
- 道具/武器名："草薙剑""苦无""日轮刀"等
- 能力体系名："查克拉""霸气""灵压"等
- 角色标志性外观描述过细（如"橙色连体衣的忍者"可能触发火影过滤）

■ 解决思路
不是简单换词，是三层替换策略：
- 层1：角色名 → 颜色+装备/特征代称（"宇智波斑"→"赤甲武者"）
- 层2：术法/能力名 → 动作效果物理描述（"火遁·豪火灭却"→"掌心巨型火墙喷涌"）
- 层3：体系概念词 → 通用武术/自然概念（"查克拉"→"气场/内力气劲"）

核心原则：精神像但文字不像——保留角色的视觉精髓和动作特色，
但用模型不会触发版权过滤的纯描述性语言表达。

══════════ SECTION:B-检测清单 ══════════
IP词汇检测清单（6类）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1读完用户剧情文本后，按以下6类扫描IP关键词：

■ 类型1：角色名
检测目标：原作中角色的真名/称号/别名
示例触发词：宇智波斑/漩涡鸣人/路飞/炭治郎/艾伦/孙悟空(龙珠)/黑崎一护等
检测方法：文本中出现日本人名/动漫角色名格式

■ 类型2：术法/能力名
检测目标：原作中角色使用的招式/术法/能力的专有名称
示例触发词：写轮眼/轮回眼/火遁/螺旋丸/千鸟/神罗天征/橡胶果实/呼吸法/始解/卍解等
检测方法：含"遁""术""眼""果实""法"等术法后缀的专有名词

■ 类型3：组织/地点名
检测目标：原作中的组织/村落/国家/地名
示例触发词：木叶村/雾隐村/海军本部/鬼杀队/调查兵团/尸魂界等
检测方法：含"村""队""团""界"等组织后缀的专有名词

■ 类型4：道具/武器名
检测目标：原作中角色使用的标志性道具/武器的专有名称
示例触发词：苦无/手里剑/日轮刀/草薙剑/斩魄刀/三相之力等
检测方法：含武器类型词的专有组合名词

■ 类型5：能力体系名
检测目标：原作中设定的能量体系/力量来源的专有名称
示例触发词：查克拉/霸气/灵压/念能力/气/法力等
检测方法：原作世界观设定的能量体系术语

■ 类型6：标志性外观描述
检测目标：过于精确的原作角色外观描述（即使不用真名也可能触发）
示例触发词："橙色连体衣的忍者"(火影鸣人)/"草帽少年"(海贼路飞)/"绿色头巾剑士"(海贼索隆)
检测方法：角色外观描述+原作标志性元素的组合

■ 检测结果处理
- 检测到任何类型 → 提示用户："检测到IP相关词汇，建议进行版权词替换。
  是否加载版权词处理指南？"
- 用户同意 → 加载本库，执行替换
- 用户拒绝 → 尊重用户选择，但分镜输出时标注风险提示
- 未检测到 → 不加载本库，正常流程

══════════ SECTION:C-替换策略 ══════════
三层替换策略
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 层1：角色名 → 颜色+装备/特征代称

原则：用角色最显著的视觉特征（颜色+装备/体型/发色）作为代号，
让AI能锚定外观但不触发IP词。

替换公式：[主色]+[装备/特征]+[身份称谓]
示例：
  宇智波斑 → 赤甲武者（赤红铠甲+武者）
  漩涡鸣人 → 橙衣少年（橙色服装+少年）
  路飞 → 草帽少年（草帽+少年）
  炭治郎 → 格纹耳饰少年（格纹耳饰+少年）

注意：
- 代号要简洁（2-4字），好记好写
- 多角色同框时，代号的颜色要有对比（赤甲vs翠甲/橙衣vs蓝衫）
- 代号在全剧保持一致，不随意更换

■ 层2：术法/能力名 → 动作效果物理描述

原则：不提术法名称，只描述"物理外观+动作效果"——
模型理解的是视觉现象，不是IP概念。

替换公式：[施法部位]+[能量形态]+[运动方向]+[效果描述]
示例：
  火遁·豪火灭却 → 掌心巨型火墙喷涌向前席卷
  写轮眼（常态）→ 血红色虹膜带黑色三勾玉图案旋转
  写轮眼（觉醒→轮回眼）→ 瞳孔紫色波纹层层扩散，血色虹膜褪为紫灰色同心环波纹
  神罗天征 → 环形斥力波以身体为中心向外扩散
  螺旋丸 → 掌心蓝色球形气劲高速旋转压缩
  千鸟 → 掌心蓝白色电弧噼啪跳动汇聚

注意：
- 描述要包含"颜色+形态+动态"三要素，让模型有明确的视觉锚点
- 连续变化（如瞳术升级）要分步骤描述，不能一笔带过
- 避免使用原作术法名的任何组成部分（"火遁"→"火墙"，不是"火遁术"）

■ 层3：体系概念词 → 通用武术/自然概念

原则：用通用武术概念或自然物理概念替代原作的能力体系术语。

替换公式：[通用概念词]
示例：
  查克拉 → 气场/内力气劲
  霸气 → 气势压迫/精神威压
  灵压 → 灵力气场
  念能力 → 精神力场
  结印 → 双手快速交叉手势
  仙术 → 自然能量强化
  木遁 → 翠绿木系术法
  须佐能乎 → 蓝色能量巨人

注意：
- 体系词替换后，全剧保持一致
- 在角色卡中标注角色的能力体系代号（如"气场型/自然能量型"）

══════════ SECTION:E-描述技巧 ══════════
"精神像但文字不像"技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 为什么要"精神像但文字不像"
即使用户不说IP名，描述太像原作也可能触发模型的安全过滤。
反过来，如果替换描述太泛（如把"写轮眼"换成"红色眼睛"），
虽然不触发过滤，但生成出来完全没有原作的感觉。

目标是：保留角色的视觉精髓和动作特色，但用模型不会触发版权过滤的纯描述性语言表达。

■ 技巧1：拆解视觉特征，不用原作术语
原作术语"写轮眼" → 拆解为"血红色虹膜+黑色三勾玉图案+旋转"
- "血红色"=颜色（保留）
- "虹膜"=解剖部位（通用）
- "三勾玉图案"=纹路形状描述（不用"勾玉"这个日本文化词，用"三瓣旋转纹"更安全）
- 最安全写法："血红色虹膜带黑色三瓣旋转纹路"

■ 技巧2：动作效果代替术法名称
原作"火遁" → 描述"火从哪里出来、什么形态、往哪个方向运动、什么效果"
- "掌心"=施法部位
- "巨型火墙"=能量形态
- "喷涌向前席卷"=运动方向+效果
- 组合："掌心巨型火墙喷涌向前席卷"

■ 技巧3：颜色对比锚定角色身份
多角色同框时，用颜色对比代替名字：
- 赤甲武者(红) vs 翠甲武者(绿) → 颜色冲突强，AI分得清
- 橙衣少年(橙) vs 黑衣剑客(黑) → 同上
- 避免用近色（红甲vs橙甲容易混）

■ 技巧4：标志性外观保留精髓
原作角色的标志性外观（如斑的铠甲、路飞的草帽）可以保留，
但用描述性语言而非原作术语：
- "草帽"→保留，草帽是通用物品不是IP词
- "橙色连体衣"→改为"橙色武道服"，"连体衣"太精确可能触发
- "护额"→改为"额系布带"，护额是火影专有词

■ 技巧5：能力体系用通用武术概念
原作"查克拉"→"气场/内力气劲"
- "气场"=中国武术通用概念，所有模型都理解
- "内力"=武侠通用概念
- "气劲"=武术通用术语
- 不要用原作造词（"查克拉""霸气""灵压"都是原作造词）

■ 技巧6：变身/觉醒分步描述
原作角色变身往往是渐进的，要分步描述而非一步到位：
- 写轮眼→轮回眼：
  步骤1："血红色虹膜中黑色三瓣纹路开始旋转加速"
  步骤2："瞳孔中心浮现紫色波纹，层层向外扩散"
  步骤3："血色虹膜褪为紫灰色，波纹凝固为同心环"
- 超级赛亚人变身：
  步骤1："黑色竖发根部开始变金，金色向上蔓延"
  步骤2："周身金色气焰从脚下升起，衣袂剧烈飘动"
  步骤3："瞳色变为碧绿，气焰稳定为火焰形态"

■ 通用原则
- 宁可多写几个字描述，也不要用原作术语走捷径
- 替换词要在全剧保持一致
- 角色卡中的代号一旦确定，全系列不改
- 替换后在分镜脚本头部写明替换说明，方便后续维护

     建议进行版权词替换以确保生成顺利。是否加载版权词处理指南？"
   - 用户同意 → 加载本库 → 执行替换 → 构建替换映射表 → 存入脚本头部

■ 替换流程
1. 从SECTION:D查找对应IP的替换参考表
2. 如不在参考表中，按SECTION:C的三层策略自行构建替换
3. 构建【版权词替换说明】写入分镜脚本文件头部
4. 全部分镜正文使用替换后的词汇
5. 角色卡中的代号使用替换后的代称

■ 与角色一致性卡的配合

1. 步骤1后：检测IP词 → 加载版权词处理指南

3. 步骤1.8：用替换后的代号构建角色卡
4. 后续步骤：全部分镜使用替换后词汇

- 替换映射表附在分镜脚本文件头部

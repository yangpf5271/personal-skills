# S级多人群战视频拍摄 SKILL  
## ——两军对垒、爆发冲阵、局部厮杀、主角破局的电影化分镜规范

适用类型：仙侠、玄幻、国漫3D、武侠、奇幻战争、古装战场。  
核心目标：**大场面看得出规模，中场面看得懂局势，近场面看得清动作；群战不乱、主角不丢、攻防有因果、情绪持续升级。**

---

# 一、S级群战的底层原则

## 1. 不要“所有人同时乱打”
多人群战最忌讳：满屏角色挥武器、特效乱飞、没有攻击目标、没有阵营方向。

必须先确定每一段战斗的：

- **双方阵营位置**：甲军在画面哪侧，乙军在哪侧；
- **主攻方向**：左→右，或右→左，整段不要随意翻轴；
- **战场纵深**：前景、中景、远景分别是谁；
- **本段目标**：夺旗、破阵、斩将、突围、守城、救人；
- **胜负变化**：谁一开始占优，谁在何处反转；
- **主角位置**：主角在哪条战线、正面面对谁、下一步要去哪里。

**一句话原则：**  
> 每一个镜头都必须让观众同时看懂“谁在打谁、往哪打、为什么打、打完局势有什么变化”。  

---

## 2. 一场群战要切成五层，不是一镜到底

### 第一层：战争格局
交代两军规模、地形、天空、旗帜、战鼓、阵势与压迫感。

### 第二层：冲阵碰撞
交代谁先冲、冲击方向、骑兵或先锋如何撕开第一道防线。

### 第三层：局部绞杀
从宏大战场切进一个小区域：盾阵、刀阵、弓箭手、法修、精锐小队。

### 第四层：主角线
镜头始终要回到主角：主角面对的强敌、战术目标、受伤与突破。

### 第五层：局势反转
敌军增援、主将出手、护城阵崩裂、妖兽降临、旗帜倒下、天象变化，推动下一阶段。

# 二、两军对垒的标准战场空间设计

## 1. 固定空间轴线

以观众视角为准，建议统一为：

| 区域 | 画面位置 | 内容 |
|---|---|---|
| 己方军阵 | 画面左侧 / 左前方 | 主角、友军、己方旗帜 |
| 敌方军阵 | 画面右侧 / 右后方 | 敌军主将、敌方旗帜 |
| 中央杀场 | 画面中央 | 冲阵、尸横、断兵、法术碰撞区 |
| 己方后阵 | 左后方 | 弓兵、法修、医疗、战鼓 |
| 敌方后阵 | 右后方 | 敌军弓阵、战车、主将台 |
| 高空战区 | 上方 | 飞剑、灵兽、雷法、御空修士 |
| 地下战区 | 下方 / 地裂 | 地刺、岩浆、土系法术、伏兵 |

### 空间连续性强制要求
- 己方角色绝大多数镜头保持**朝右攻击**。  
- 敌方角色绝大多数镜头保持**朝左攻击**。  
- 若必须换方向，先用一个俯拍大全景或环绕镜头重新建立轴线。  
- 主角从左军冲入中央后，不能下一镜无过渡出现在敌方最右后阵。  
- 每一次突破都要补一镜：**冲过谁、越过什么、落在哪里。**

---

## 2. 战场要有“可识别地标”

防止场景漂移，至少固定 5 个资产：

1. **己方主旗**：颜色、图腾固定；  
2. **敌方主旗**：颜色与形状和己方明显不同；  
3. **中央地形**：壕沟、巨石、断桥、血色河床、石碑阵或废墟；  
4. **高点建筑**：城墙、山坡、祭坛、烽火台；  
5. **战场天气**：黄沙、暴雨、雪夜、夕阳、雷云、黑雾只能选一套主基调。  

**举例：仙侠战场资产库**  
- 己方：青白旗帜、银甲剑修、青色剑光；  
- 敌方：黑赤旗帜、黑甲妖兵、猩红煞气；  
- 中央：断裂古战道、半塌石碑、燃烧战车；  
- 天空：翻涌黑云、雷光不时劈落；  
- 地面：碎甲、断旗、裂缝、飞灰、灵火残焰。

# 三、S级群战镜头结构

## 阶段A：战前压迫｜6—10秒
目的：建立规模、阵营、情绪和爆发前的静。

### 必备镜头
1. **高空超远景**：两军隔着战场对峙，旗帜、军阵、地形全部清晰。  
2. **地面低机位**：战靴、战马、兵器、握紧的手，营造压迫。  
3. **主角特写**：眼神、掌心灵力、握刀、压低呼吸。  
4. **敌将特写**：冷笑、抬手、战旗落下，作为开战信号。  

### 节奏要点
- 开战前不要立刻铺满爆炸；  
- 用“安静—局部细响—鼓点—爆发”制造蓄力；  
- 鼓点、风声、盔甲摩擦、战马喷气声比台词更重要。

---

## 阶段B：第一轮冲阵｜10—18秒
目的：展示两军真正撞上，而不是隔空放技能。

### 标准攻防链
`战鼓落下 → 前锋冲刺 → 弓箭/术法压制 → 盾阵顶住 → 骑兵或重甲撞入 → 两军兵器首次碰撞 → 中央地带失控`

### 镜头组合
- 高空俯冲：己方先锋向右突进；  
- 贴地跟拍：战马、冲锋者、碎石向后飞溅；  
- 横向平移：两排长枪或盾牌迎面碰撞；  
- 极近特写：枪尖、剑锋、手部、瞳孔；  
- 广角拉远：中央战线被撞出凹口。

### 动作逻辑
不是“人冲过去就飞”，而是：

`加速冲刺 → 兵器先触 → 身体受力后仰 → 阵线挤压变形 → 后排顶上 → 被击飞者撞倒后方友军 → 缺口形成。`

---

## 阶段C：局部绞杀｜15—25秒
目的：让宏大战场有可感知的具体战斗。

每个局部战区只聚焦 **3—8个可识别角色**，不能一镜塞几十张脸。

### 可轮换的局部模块

#### 模块1：盾阵硬顶
`敌军重锤砸下 → 己方盾阵下沉承压 → 盾面裂纹扩散 → 后排灵力注入 → 盾阵反推 → 敌军脚下地面崩裂。`

#### 模块2：骑兵穿插
`骑兵从侧翼切入 → 长枪横扫挑飞敌兵兵器 → 战马跃过尸堆或断车 → 斜切敌阵 → 镜头升空展示阵线被切开。`

#### 模块3：弓箭与法术压制
`后阵抬弓 / 掐诀 → 箭雨或术法从己方左后方射向右前方 → 敌军举盾 → 地面爆开 → 镜头切回主角借爆炸烟尘突入。`

#### 模块4：空中剑修对撞
`飞剑列阵升空 → 敌方煞气巨兽冲出云层 → 剑阵穿云俯冲 → 空中交错 → 残剑与灵光坠入地面战场。`

---

## 阶段D：主角破局｜15—25秒
目的：从“战争大场面”收束到“主角爽点”。

主角必须有明确任务，例如：

- 斩敌方先锋；
- 破掉敌军阵眼；
- 抢回军旗；
- 救出被围困的师姐；
- 穿过乱军斩将；
- 阻止敌方术法蓄力。

### 主角破局标准链条
`发现弱点 → 被敌军阻拦 → 付出代价 → 借地形/借敌方力量 → 突入核心 → 一击破局 → 战局暂时倒向己方。`

### 镜头逻辑示例
`主角被三名敌兵夹击 → 左侧敌刀横斩、正面长枪突刺、右侧法球压来 → 主角低身滑步避刀 → 剑格开长枪并借力扭转枪杆 → 将正面敌兵撞向右侧法球 → 爆炸烟尘遮蔽 → 主角从烟尘上方跃出，斩断阵眼旗杆。`

关键：  
- 主角动作必须由前一镜的姿势接到下一镜；  
- 攻击来源必须明确方向；  
- 一次高光动作不要超过 2—3 个核心动作；  
- 大招前先给蓄力、环境响应、敌方反应；  
- 大招后必须给破坏结果和人物余韵。

---

## 阶段E：反转升级｜8—15秒
目的：让本集不止“打赢一架”，而是留住观众。

### 常见反转
- 己方以为破阵，敌方主将却借机放出第二阵眼；  
- 主角斩杀先锋，但敌军真正统帅现身；  
- 战场地底裂开，巨物妖兽苏醒；  
- 己方军旗被毁，士气崩盘；  
- 师姐为救主角暴露真正力量；  
- 天空法阵完成，整片战场被困。  

### 结尾镜头公式
`短暂寂静 → 所有人抬头 / 回头 → 巨大未知物进入画面 → 音乐骤停 → 黑场。`

# 四、群战运镜库：镜头必须服务于战局

| 用途 | 推荐运镜 | 画面效果 |
|---|---|---|
| 展示两军规模 | 高空俯拍、航拍横移、持续拉远 | 大、稳、清楚 |
| 冲阵速度感 | 贴地跟拍、FPV穿阵、低机位前冲 | 快、狠、压迫 |
| 两军正面碰撞 | 横向平移、正面后拉、震动镜头 | 阵线冲击 |
| 主角突围 | 环绕跟拍、侧后跟拍、希区柯克变焦 | 主角突出 |
| 刀剑近战 | 近身手持感、短促横移、动作定格 | 看清招式 |
| 重击与爆炸 | 撞击定格、镜头震动、快速拉远 | 力量反馈 |
| 法术覆盖战场 | 高空俯冲、仰拍升空、横向掠过 | 法术规模 |
| 局势反转 | 从人物上摇至天空、由局部拉至大全景 | 危机扩大 |

## 禁止事项
- 全程FPV乱飞；  
- 连续多镜同样的横扫或爆炸；  
- 镜头运动比人物动作更快，导致看不清战斗；  
- 每个角色都飞天、每件兵器都发光；  
- 只拍主角脸，不交代战场胜负；  
- 只拍大全景，不让观众看清谁赢谁输。

# 五、多人群战的景别配比

以 **90—120秒群战短剧** 为例：

| 景别类型 | 推荐占比 | 作用 |
|---|---:|---|
| 超远景 / 远景 | 15% | 建立战场、重置空间轴 |
| 全景 / 大全景 | 25% | 展示冲阵、阵形、群体动作 |
| 中景 | 25% | 交代小队交锋与角色关系 |
| 中近景 | 15% | 主角拆招、同伴配合 |
| 特写 / 局部特写 | 15% | 眼神、手势、兵器碰撞、阵眼 |
| 主观 / 非常规机位 | 5% | 高光、受击、飞剑、坠落 |

**规则：**  
连续两个特写后，必须回到中景或全景重建空间。  
连续两个大全景后，必须切进局部人物，让观众有情绪落点。

# 六、仙侠多人群战的特效分层

## 1. 环境层：始终存在，但不能抢戏
- 风沙、灰烬、飘雪、雨水、黑雾；
- 战旗飘动、断旗燃烧、碎石滚落；
- 远处术法闪烁、地面微震；
- 天空云层被灵压推开。

## 2. 战术层：阵营可识别
- 己方统一青白、金白、玄黄等克制色；
- 敌方统一黑赤、土黄、暗紫等压迫色；
- 箭雨、盾阵、剑阵、法阵必须有固定视觉语言；
- 同阵营特效不要颜色乱跳。

## 3. 动作层：只跟着攻击走
- 剑气跟剑锋轨迹；
- 拳风跟拳头受力方向；
- 地刺由地下向上破出；
- 雷法由天到地劈落；
- 卸力气流沿角色转腰、沉肩、滑步方向流动。

## 4. 高光层：只给关键一击
高光瞬间可用：

`短暂停顿 → 环境静音半拍 → 能量压缩 → 一击释放 → 冲击波扩散 → 敌我双方反应 → 余波落尘。`

# 七、群战音效设计

## 环境音
- 战鼓、号角、风声、战马嘶鸣；
- 战旗猎响、盔甲碰撞、远处呐喊；
- 城墙崩裂、巨物踏地、飞鸟惊起。

## 动作音
- 刀剑：金属摩擦、破风、钝击；
- 术法：低频灵压、元素爆裂、能量回响；
- 重击：先低频闷响，再碎石喷射，再余震；
- 受击：衣料撕裂、脚步滑地、撞甲、翻滚。

## 高光静音法
主角或主将关键一击前，环境声可瞬间抽空 0.2—0.5秒，只保留心跳或耳鸣；击中后再让所有声音一起回灌，冲击力会明显提升。

# 十、群战输出前强制自检

输出分镜前逐项检查：

- [ ] 每个阵营是否有固定颜色、旗帜、服装与武器语言？  
- [ ] 己方和敌方的攻击方向是否全程稳定？

## 🧩 总架构：参数拼装公式（已更新：空间+道具信息前置）

```
【空间锚】+【状态锁】+【道具锁】+【光影锁】+【声音锁】+【交接帧(跨视频时)】→【画质风格】+【镜头机位】+【构图画幅】+【场景环境】+【人物状态】
+【动作动势】+【光影色彩】+【特效层级】+【时长台词】→ 末尾【负面提示(仅模板B)】
```
> 铁律：顺序不可乱。生成模型对提示词**前重后轻**，空间锚、状态锁和道具锁永远最前面（画质风格之前），负面提示（仅模板B）永远垫底。
> [空间锚]、[状态锁]和[道具锁]不计入画面描述字数限制，每镜强制复写。详见 references/空间连续性控制库.txt

## 参数域⑫：书写语法规范

| 规则 | 说明 |
|---|---|
| 优先级 | 全局参数管全集统一（风格/画质/角色锚定）；单镜参数只管本镜差异（镜头/动作/光影） |
| 覆盖原则 | 单镜参数与全局冲突时，**单镜覆盖全局**，且需在单镜标注【覆盖：××】 |
| 权重写法 | 重点参数可加权重：`（金色剑芒：1.3）`，最多3处，滥用会崩 |
| 分隔符 | 参数域间用逗号，子项用顿号，层级用竖线 |
| 长度 | 单镜画面描述150-250字，超出砍环境不砍动作 |

## 景别递进规则（防止景别乱跳）

### 递进方向

| 方向 | 效果 | 适用 | 示例 |
|---|---|---|---|
| 递进（远→近） | 压迫感增强、情绪收紧 | 蓄力、铺垫、逼近真相 | LS→FS→MS→MCU→CU |
| 递退（近→远） | 释放感、孤立感、渺小感 | 余波、结局、离场 | CU→MCU→MS→FS→LS |
| 对称（远→近→远） | 情绪弧线完整 | 完整段落 | LS→...→CU(峰值)→...→LS |
| 跳跃（特写→大全景） | 震惊、反差、荒诞 | 喜剧、惊吓、反转 | CU→ELS（禁止随意使用） |

### 景别铁律
1. **相邻镜头景别差≤2级**——CU→MS可以，CU→LS是跳崖（除非故意制造震惊）
2. **对话戏用正反打**——MCU/MS交替，A说话时拍A，B说话时拍B，不混
3. **情绪峰值用特写**——打脸金句、震惊、反转用CU/ECU
4. **场景建立用大全景**——每段开头给一个LS/ELS交代空间
5. **打斗三连拆景别递进**——起手MLS→碰撞MS→结果CU（越来越近）
6. **禁止来回跳**——CU→LS→CU→LS是"景别癫痫"，观众晕

### 对话戏景别节奏

## 视线匹配（对话戏视线不接的根因和解法）

### 问题
A角色看画面右侧说话，切到B角色也看画面右侧——两人视线同向，不像在对话。
根因：AI模型不理解"180°线"概念，每镜独立生成时角色朝向随机。

### 视线匹配规则
1. **180°线法则**：对话的两个人之间有一条虚拟轴线，摄像机始终在轴线同一侧
   - A在画面左侧面向右，B在画面右侧面向左 → 视线交汇 ✓
   - A面向右，B也面向右 → 视线同向，不像对话 ✗
2. **正反打方向固定**：
   - 拍A时A看右 → 切到B时B必须看左
   - 全段对话中这个方向不能翻转
3. **过肩镜头维持同一侧**：
   - 过肩拍A（A在左，B的肩膀在右前景）→ 过肩拍B时B在右，A的肩膀在左前景
   - 不能突然变成B在左A在右（跳轴）
4. **视线高度匹配**：
   - 站着的人对话：平视
   - 站着vs坐着：站着的人微俯视，坐着的人微仰视
   - 不能两人都平视（高度不匹配）

### 状态锁中标注视线方向
在[状态锁]中增加视线方向标注：
```
[状态锁]角色A=站立/画面左侧/面朝右，角色B=站立/画面右侧/面朝左
```
这样模型生成时能明确两人的朝向关系，防止视线不匹配。

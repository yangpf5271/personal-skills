## 🎬 01 — 大卫·林奇电影美学（David Lynch Cinematic Aesthetics）

### 基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 大卫林奇电影美学 |
| **英文名** | David Lynch Cinematic Aesthetics |
| **风格关键词** | 超现实主义、梦境逻辑、暗黑童话、心理惊悚、舞台剧式构图 |

### 完整 Prompt 结构

```
【核心基调】
Lynch 式超现实氛围人物、幽闭空间或舞台、戏剧性红与黑的强烈对比。
主光源单一且不自然，制造不安感。

【色彩方案】
整体低饱和度偏冷灰蓝底色，局部高饱和红色点缀（幕布/灯光/唇色），
形成令人不安的色彩对冲。阴影深黑几乎无细节。

【光影系统】
高对比度、戏剧性顶光或侧光。主体不受光面陷入黑暗。
阴影边缘硬朗，类似舞台聚光灯效果。

【质感肌理】
胶片颗粒感明显，中等偏粗。
场景带有轻微失焦或模糊区域，模拟梦境/记忆的不确定性。

【构图特征】
中心对称或严格几何构图。人物常处于被凝视状态。
画面存在"第四面墙"打破感——仿佛观众也在被注视。

【禁止项】
× 明亮欢快色调
× 自然柔和光线
× 高饱和多色系
× 清晰锐利画质
```

### 提示词串

**正向：**
```
大卫林奇电影美学调色，超现实氛围，冷灰蓝低饱和底色，
局部高饱和红点缀，红黑强烈对比，单一不自然强光源，
戏剧性顶光侧光，硬朗阴影边缘，舞台聚光灯效果，
中等偏粗胶片颗粒，轻微失焦模糊，梦境不确定性，
中心对称几何构图，打破第四面墙凝视感，深黑无细节阴影
```

**反向：**
```
明亮欢快色调 · 自然柔和光线 · 高饱和多色系 ·
清晰锐利画质 · 均匀漫射光 · 暖黄温馨 ·
低对比柔调 · 现代数字干净质感
```

### 调色参数拆解

| 维度 | 具体设定 | 效果说明 |
|------|---------|---------|
| **基础色调** | 冷灰蓝底 + 局部高饱和红 | 不安、紧张、超现实 |
| **对比度** | 极高 | 戏剧性、舞台感 |
| **光影** | 单一强光源、硬边阴影 | 不自然、心理压迫感 |
| **饱和度** | 整体低 + 点状高饱和 | 视觉焦点强制引导 |
| **质感** | 中等偏粗胶片颗粒 | 复古、梦境感 |
| **构图** | 几何对称 + 打破第四面墙 | 被凝视的不适感 |
| **适用题材** | 心理惊悚、超现实短片、艺术摄影、时尚大片 | — |

### 代表作参考
《穆赫兰道》《双峰》《象人》《蓝丝绒》《内陆帝国》

## 🏮 02 — 港风复古中式电影美学（Hong Kong Retro Chinese Film Aesthetics）

### 基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 港风复古中式电影美学 |
| **英文名** | Hong Kong Retro Chinese Film Aesthetics |
| **风格关键词** | 港式怀旧、中式古典、柔光朦胧、青绿山水、汉服雅韵 |

### 完整 Prompt 结构

```
【核心基调】
80-90年代港片复古氛围，结合中国传统美学元素。
画面充满柔美朦胧的诗意感，如老港片的滤镜质感遇上水墨画意境。

【色彩方案】
整体低饱和暖黄绿调为主，肤色呈现健康自然的蜜糖色。
背景偏向青绿色（园林/植物），与人物暖肤色形成和谐互补。
避免过于鲜艳的现代数码色，保持胶片褪色的温润感。

【光影系统】
柔和漫射自然光为主，类似阴天或树荫下的散射光。
面部受光均匀，无明显硬阴影。
可适当加入逆光轮廓光（发丝光），增加层次和仙气。

【质感肌理】
细腻胶片颗粒，轻微柔焦效果。
画面略带朦胧感（atmospheric haze），营造梦幻回忆氛围。
服装面料纹理清晰（丝绸/纱质汉服的光泽感）。

【构图特征】
中式留白构图，人物居中或黄金分割。
前景可有虚化元素（花枝/柳帘）作为画框。
环境融入传统建筑/园林元素（亭台/回廊/荷塘/假山）。

【禁止项】
× 现代高饱和广告色
× 硬朗直射阳光
× 过度锐化/清晰
```

### 提示词串

**正向：**
```
港风复古中式电影调色，80-90年代港片质感，
低饱和暖黄绿调，蜜糖肤色，青绿背景互补，
胶片褪色温润感，柔和漫射自然光，阴天散射光，
面部均匀受光无硬阴影，逆光发丝轮廓光，
细腻胶片颗粒轻微柔焦，朦胧梦幻回忆氛围，
中式留白构图，前景虚化画框，丝绸纱质面料光泽
```

**反向：**
```
现代高饱和广告色 · 硬朗直射阳光 · 过度锐化清晰 ·
数码干净质感 · 冷蓝调 · 高对比硬阴影 ·
霓虹荧光色 · 平面化无层次
```

### 调色参数拆解

| 维度 | 具体设定 | 效果说明 |
|------|---------|---------|
| **基础色调** | 暖黄绿底 + 蜜糖肤色 | 怀旧、温柔、复古港风 |
| **对比度** | 低~中等 | 柔和、不刺眼 |
| **光影** | 漫射自然光 + 发丝逆光 | 仙气、梦幻、朦胧 |
| **饱和度** | 整体偏低 + 局部保留 | 胶片褪色感 |
| **质感** | 细腻颗粒 + 柔焦 | 回忆感、诗意 |
| **构图** | 中式留白 + 前景画框 | 传统美学、雅致 |
| **适用题材** | 古风写真、汉服摄影、国潮广告、文艺短片 | — |

## 🔪 03 — 希区柯克电影美学（Hitchcock Film Aesthetics）

### 基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 希区柯克电影美学 |
| **英文名** | Hitchcock Film Aesthetics |
| **风格关键词** | 悬疑惊悚、黑色电影、窥视视角、经典好莱坞、心理张力 |

### 完整 Prompt 结构

```
【核心基调】
50-60年代好莱坞悬疑片氛围，充满不安和心理张力。
画面暗示"即将发生什么"，观众处于窥视者位置。

【色彩方案】
经典黑白或低饱和彩色（希区柯克后期彩色片风格）。
若用彩色：偏暗的棕褐色调、深绿色、暗金色。
关键色彩：阴影中的深黑、皮肤的中性灰调、偶尔的高亮（灯光/反光）。

【光影系统】
强烈的明暗对比（chiaroscuro），类似德国表现主义影响。
主要光源来自画面内部（台灯/窗户/壁灯），产生方向性强的阴影。
人物面部常半明半暗，隐藏表情细节，增加神秘感。

【质感肌理】
经典胶片质感，银盐黑白或早期彩色胶片。
画面干净但不过于锐利，保留胶片的有机感。
可带轻微的 vignette（暗角），聚焦视线到中心。

【构图特征】
窥视视角——透过窗户/门缝/百叶窗拍摄。
人物常处于画面边缘或不稳定位置。
使用纵深线条（走廊/楼梯/铁轨）增强不安感。
镜像反射、双重曝光等超现实元素可适度使用。

【禁止项】
× 明亮均匀布光
× 现代鲜艳色彩
× 稳定安全构图
```

### 提示词串

**正向：**
```
希区柯克电影美学调色，50-60年代好莱坞悬疑片氛围，
棕褐深绿暗金色调或经典黑白，强烈明暗对照法chiaroscuro，
画面内部方向性光源（台灯窗户壁灯），半明半暗面部，
隐藏表情神秘感，经典银盐胶片质感，轻微暗角vignette，
窥视视角构图，纵深线条增强不安，镜像反射双重曝光，
心理张力不安感，窥视者位置
```

**反向：**
```
明亮均匀布光 · 现代鲜艳色彩 · 稳定安全构图 ·
高饱和暖调 · 柔和漫射光 · 数码干净质感 ·
平面化无纵深 · 轻松愉快氛围
```

### 调色参数拆解

| 维度 | 具体设定 | 效果说明 |
|------|---------|---------|
| **基础色调** | 棕褐/深绿/暗金 或 经典黑白 | 复古悬疑、经典好莱坞 |
| **对比度** | 高（明暗对照法） | 戏剧性、不安感 |
| **光影** | 方向性强光源、半明半暗 | 隐藏信息、心理张力 |
| **饱和度** | 低（偏暗调） | 压抑、神秘 |
| **质感** | 经典银盐胶片 + 暗角 | 有机感、聚焦视线 |
| **构图** | 窥视视角 + 纵深线条 | 不安、被观察感 |
| **适用题材** | 悬疑片、惊悚片、黑色电影、侦探故事 | — |

### 代表作参考
《惊魂记》《后窗》《迷魂记》《群鸟》《火车怪客》

## 🎭 04 — 雅克·塔蒂电影美学（Jacques Tati Cinematic Aesthetics）

### 基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 雅克塔蒂电影美学 |
| **英文名** | Jacques Tati Cinematic Aesthetics |
| **风格关键词** | 法式现代主义喜剧、极简几何、冷幽默、秩序与荒诞、60年代摩登 |

### 完整 Prompt 结构

```
【核心基调】
1960年代法国现代主义喜剧氛围，冷幽默式的荒诞日常。
画面极度整洁有序，但在秩序中隐藏着微妙的滑稽感。

【色彩方案】
高度克制的中性色调：大面积白色/浅灰/米白。
点缀色极少且克制（淡蓝/浅黄/淡粉），通常来自小物件或服装。
整体看起来像建筑杂志或产品设计目录的色调。

【光影系统】
均匀平坦的漫射光，几乎没有阴影。
类似阴天或大型柔光箱的效果，所有细节都清晰可见。
荧光灯管或大面积天光是典型光源，产生均匀照明。

【质感肌理】
极其干净锐利的画质，近乎无菌感。
光滑表面（玻璃/金属/塑料）的反光清晰但不刺眼。
没有胶片颗粒或复古质感，强调现代性和人工性。

【构图特征】
严格的几何构图，大量直线、平行线、重复图案。
人物在巨大的空间中显得渺小（办公室/工厂/机场/商场）。
广角镜头夸张空间的纵深感和空旷感。
对称构图为主，偶尔打破对称制造笑点。

【禁止项】
× 温暖情感化色调
× 强烈明暗对比
× 杂乱/混乱的画面
× 胶片颗粒/复古质感
```

### 提示词串

**正向：**
```
雅克塔蒂电影美学调色，1960年代法国现代主义喜剧，
极简几何构图，大量直线平行线重复图案，
白灰米白中性色调，极少克制点缀色（淡蓝浅黄淡粉），
均匀平坦漫射光无阴影，荧光灯管大面积天光，
极其干净锐利无菌感，光滑表面清晰反光，
广角夸张空间纵深感，人物渺小感，对称构图，
秩序中荒诞冷幽默
```

**反向：**
```
温暖情感化色调 · 强烈明暗对比 · 杂乱混乱画面 ·
胶片颗粒复古质感 · 高饱和点缀 · 柔焦朦胧 ·
手持晃动感 · 暖黄底色
```

### 调色参数拆解

| 维度 | 具体设定 | 效果说明 |
|------|---------|---------|
| **基础色调** | 白/灰/米白 + 极少点缀 | 极简、现代、冷峻 |
| **对比度** | 极低 | 平坦、均匀、无戏剧性 |
| **光影** | 均匀漫射、无阴影 | 无菌感、人工性 |
| **饱和度** | 极低 | 克制、产品级 |
| **质感** | 锐利干净、无颗粒 | 现代、精确、产品级 |
| **构图** | 几何重复、广角纵深 | 秩序中的荒诞 |
| **适用题材** | 现代喜剧、讽刺短片、广告、建筑摄影 | — |

### 代表作参考
《我的舅舅》《游戏时间》《交通意外》

## 🔫 05 — 昆汀·塔伦蒂诺风格（Tarantino Film Aesthetics）

### 基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 昆汀塔伦蒂诺电影胶片调色 |
| **英文名** | Tarantino Film Aesthetics |
| **风格关键词** | 复古美式西部、高对比撞色、胶片颗粒、暴力美学、非线性叙事 |

### 完整 Prompt 结构

```
【核心基调】
90年代美式独立电影复古氛围，暴力美学与黑色幽默并存。
画面充满浓郁胶片质感和强烈色彩对冲，致敬B级片和西部片。

【色彩方案】
高光浓郁暖金黄，暗部偏紫青蓝绿色调，形成强烈对冲撞色。
绿色压暗为灰橄榄调，蓝色深冷调。
阴影不死黑、高光不惨白，复古美式西部电影色彩。

【光影系统】
硬朗直射阳光，清晰锐利光影切分。
高对比度明暗分割，铝箔般镜头眩光。
中高对比度，硬朗明暗光分割。

【质感肌理】
90年代柯达Gold 200白光胶片颗粒质感。
粗粝复古胶片颗粒，轻微厚重自然胶片灰雾。
扎实胶片质感，洗淡柔和暗角。

【构图特征】
低角度仰拍人物英雄感，脚部特写标志性构图。
车内对话固定机位正反打，餐厅/酒吧场景长桌纵深。
非线性叙事不需特殊构图配合，但画面需有复古海报感。

【禁止项】
× 低对比柔和光影
× 低饱和莫兰迪
× 柔焦朦胧
× 清新白昼色调
```

### 提示词串

**正向：**
```
昆汀塔伦蒂诺电影胶片调色，
90年代柯达Gold 200白光胶片颗粒质感，
粗粝复古胶片，轻微厚重自然胶片灰雾，
中高对比度，硬朗明暗光分割到光影，
```

### 完整 Prompt 结构

```
【核心基调】
未来都市暗黑美学，高科技低生活的视觉化表达。

人被技术异化，被城市吞噬，在霓虹与雨幕中迷失。

【色彩方案】**
高饱和霓虹色——粉紫/青蓝/翠绿/暖红/电子黄为主。
暗黑底色——深蓝黑/暗紫黑/墨绿黑作为画面基底。
霓虹色之间形成色彩碰撞——粉紫vs青蓝、暖红vs翠绿。
肤色被霓虹染色——面部同时受到多种霓虹光源照射，色彩斑驳。
高光区域色彩溢出bloom，霓虹光晕弥漫。

【光影系统】**
霓虹光源是核心——招牌/屏幕/全息投影/LED构成画面光源。
雨面反射霓虹——地面永远是湿润的反光镜面。
体积光——霓虹光束穿过雨幕/蒸汽形成可见光柱。

高对比——霓虹高光vs深黑阴影，中间灰阶极少。

【质感肌理】**

框中框——透过窗户/屏幕/全息投影/广告牌框定人物。

【禁止项】**
× 明亮均匀日光
× 自然柔和乡村色调
× 干燥无反光表面
× 低饱和莫兰迪
× 宽广开阔空旷空间
```

### 1. 选择策略
根据项目**情绪需求**选风格，而非随意混搭：
- 心理惊悚/超现实 → 01林奇 / 03希区柯克 / 18黑色Noir

- 治愈童话/品牌广告 → 09韦斯安德森 / 07是枝裕和
- 暗黑悬疑/复仇 → 10朴赞郁 / 18黑色Noir

- 科幻/大场面 → 12诺兰 / 13维伦纽瓦 / 15雷德利斯科特 / 19赛博朋克
- 社会写实/阶级叙事 → 14奉俊昊

- 冬季/文艺/忧郁 → 06俄式阴郁

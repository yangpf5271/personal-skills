钩子卡点设计库
references/钩子卡点设计库.txt ｜ V1.0
定位：步骤1节奏推算的时间锚点源 + 每集首尾帧的设计说明书
配套：节拍库 / 台词系统⑩ / episode-planning.md / 音效词库
════════════════════════════════════════════════════════════

【总纲·三条铁律】
① 留存漏斗：3秒拦人 → 7秒立信 → 15秒锁爽 → 30秒锁追
   短剧留存70%由前3秒决定——S级与A级的分水岭不在画面，在此处
② 钩子是承诺，爆点是兑现，留钩是新承诺——三者必须闭环，
   只承诺不兑现=骗子剧，只兑现不承诺=流水账
③ 钩爆强度守恒：开篇钩强度 ≤ 本集最大爆点强度
   钩比爆点强 = 观众被骗进来，失望值加倍，弹幕反噬

══════════ SECTION:S1-开场钩子6型 ══════════
第一域｜6型开场钩子（0-3秒生死线）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【每型格式】定义｜结构公式｜逐秒分解｜示例｜适用题材｜翻车点

■ 钩型1：悬念钩
定义：展示一个"不该存在"的画面，不给解释——用信息缺口钩住人
公式：反常现象(0-1s) + 确认非幻觉(1-2s) + 疑问悬置(2-3s) = "怎么会？"
心理机制：完形缺口——大脑无法忍受未闭合的信息，会主动追看闭合
逐秒分解：
  0-1s：反常物/反常行为直接怼脸（★禁止任何环境铺垫空镜）
  1-2s：第二信息确认"这是真的"（旁人反应/特写放大/声音佐证）
  2-3s：切走或定格，疑问留给观众，正叙开始
示例：
  重生文：灵堂遗照上的女人，正站在自己棺材前嗑瓜子
  都市文：董事长会议上，西装男人给保洁阿姨递茶："妈，慢点。"
  仙侠文：渡劫雷云劈到一半，突然转弯劈向观礼席
适用：全题材通用，悬疑/重生/马甲首选
翻车点：①反常拖到第5秒才出现（人早划走了）
        ②反常之后立刻解释（缺口闭合=钩死）

■ 钩型2：冲突钩
定义：不从故事开头讲，从冲突顶点切入（in medias res）
公式：冲突顶点帧(0-1s) + 命中爆发(1-2s) + 死寂定格(2-3s) = "打起来了！"
逐秒分解：
  0-1s：动作已在最高点（耳光已在空中/刀已架脖/辞职信已离手）
  1-2s：命中+音效爆点帧（"啪"与命中帧逐帧对齐）
  2-3s：死寂定格，双方关系一个画面说清
示例：
  宅斗文：耳光脆响，养女捂脸，真千金冷收手："这一巴掌，教你认人。"
  职场文：辞职信甩上总裁脸："收购你公司的人，是我。"
  男频文：战神一脚踹翻酒桌："谁动的我女儿？"
适用：男频战神/宅斗断亲/复仇/职场
翻车点：①打得热闹但观众分不清谁打谁（关系必须在定格帧一目了然）
        ②顶点帧前有>0.5s蓄力（蓄力=给观众划走的时间）

■ 钩型3：反差钩
定义：同一个人/场景，0.5秒内从A面翻到B面
公式：A面极致(0-1s) + 撕裂动作(1-1.5s) + B面定格(1.5-3s) = "卧槽？！"
逐秒分解：
  0-1s：A面越极致越好（窝囊/华贵/哭泣/卑微）
  1-1.5s：撕裂动作（摘工牌/撕支票/抬眼/起身）——单动作≤0.5s
  1.5-3s：B面定格（气场全开/真身份/冷笑）
示例：
  赘婿文：跪着擦地的赘婿接了个电话，起身时满厅大佬齐起立
  大女主：产床上刚生完被婆婆骂，她拔针下床："离婚协议，签。"
  甜宠文：灰姑娘被泼酒，抹脸反手开瓶回敬："82年的？洗手正好。"
适用：大女主/赘婿/马甲/甜宠
翻车点：①A面不够惨（反差幅度=钩子强度，温吞=无钩）
        ②撕裂动作超过1s（节奏拖沓，爽感泄气）

■ 钩型4：身份钩
定义：低身份被踩进泥里的同一帧，高身份露出一角
公式：被踩(0-1s) + 身份碎片闪现(1-2s) + 知情者震惊(2-3s) = "她到底是谁？"
逐秒分解：
  0-1s：羞辱进行中（被泼水/被赶/被嘲讽）
  1-2s：身份碎片特写（手机屏亮出"董事会"来电/颈间玉佩/车牌号）
  2-3s：知情人瞳孔地震，被本人一个眼神制止
示例：
  马甲文：被开除的小职员走出大厦，三辆劳斯莱斯齐停，
          黑衣人鞠躬："恭迎少主回京。"
  团宠文：被嘲的农村姑娘抬手掠发，腕间全球限量腕表一闪，
          对面名媛脸色骤变
适用：马甲/团宠/隐藏大佬
翻车点：①身份直接说破（碎片≠宣告，露一角而非掀桌子）
        ②缺知情人反应（没人震惊=观众不知道这信息值钱）

■ 钩型5：死亡钩
定义：死亡/重生/绝境瞬间作为开场锚点——重生题材标配
公式：死亡进行中(0-1s) + 执念遗言(1-2s) + 睁眼逆转(2-3s) = "死了？！活了？！"
逐秒分解：
  0-1s：死亡已不可逆（毒酒已饮/坠楼失重/车祸撞击帧）
  1-2s：死者视角执念（"若能重来，我要你们——"）
  2-3s：睁眼——回到过去/陌生身体/自己灵堂
示例：
  重生文：知微被灌毒酒，再睁眼坐在自己灵堂，听着哀乐嗑供果
  虐文：她签完器官捐献书笑了："这颗心，本来就该还她。"
适用：重生/穿书/复仇/虐文
翻车点：①死亡过程拖>2s（观众以为点错剧）
        ②重生后没有立刻带前世记忆杀气（白白浪费情绪势能——
          睁眼第一帧的眼神必须是"死过一次的人"）

■ 钩型6：禁忌钩
定义：展示一段"不该发生"的关系/场景一角，游移伦理边缘
公式：禁忌一角(0-1s) + 关系确认(1-2s) + 被撞破风险(2-3s) = "他们……？！"
逐秒分解：
  0-1s：暧昧/禁忌画面只给一角（交握的手/同一盏茶/黑暗中轮廓）
  1-2s：关系身份揭示（叔嫂/师徒/仇人之子）
  2-3s：门外脚步声/灯亮——被撞破的悬念悬置
示例：
  禁忌恋：深夜祠堂，她给亡夫上香，小叔子从背后捂住她的嘴
  复仇文：仇人婚礼上新娘敬茶的手在抖——她认得台下那个"死人"
适用：禁忌恋/宅斗伦理/复仇
翻车点：①过线（平台审核红线：擦边≠越线，给"关系"不给"动作"）
        ②禁忌感靠旁白解释而非画面呈现（说出来=LOW，演出来=S级）

【6型选择矩阵】
重生复仇 → 死亡钩 > 冲突钩
马甲团宠 → 身份钩 > 反差钩
宅斗断亲 → 冲突钩 > 禁忌钩
男频战神 → 冲突钩 > 身份钩
悬疑     → 悬念钩 > 死亡钩
甜宠     → 反差钩 > 悬念钩
复合规则：允许两型叠加（死亡钩+冲突钩=灵堂打人），
  ★禁止三型以上叠加（信息过载=等于无钩）

【开场钩验收四问】（缺一即重写）
① 第1帧是否有"不该存在的东西"？（环境空镜开场=废帧）
② 3秒内观众能否说清"谁和谁、什么仇"？
③ 主角脸是否在3秒内出现？（无脸=无代入）
④ 钩子是否留下未闭合的问题？（当场闭合=钩死）

══════════ SECTION:S2-四档卡点节奏 ══════════
第二域｜四档卡点节奏（单集时间锚点）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【四档总览】
卡位    ｜时间窗  ｜功能              ｜失败后果
3秒钩   ｜0-3s   ｜拦截划走          ｜完播率崩
7秒反转 ｜3-10s  ｜立信："这剧有货"  ｜留存腰斩
15秒爆点｜10-25s ｜首次爽感兑现      ｜跳出率峰值
30秒留坑｜25-35s ｜锁定追完动机      ｜完播率低

■ 卡位1：3秒钩（0-3s）
内容要求：从6型选1-2型；主角脸+核心冲突物必须出现
信息配额：≤2个信息点（人+反常），超载=无钩
验收法：给没看过剧本的人看3秒，他能说出"哪里不对劲"=合格

■ 卡位2：7秒反转（3-10s）
功能：钩子的第一次半兑现，证明"本剧不是标题党"
公式：观众预期A → 实际是B（B比A更狠/更惨/更爽）
示例：观众以为灵堂闹鬼（A）→ 其实是死者重生回来收账（B）
内容要求：
  ① 必须翻转钩子建立的第一预期（翻转别的=脱靶）
  ② 反转后信息量比钩子多50%（让观众尝到"信息红利"）
  ③ 反转后立刻进正叙——★禁止连环反转
    （3s钩+7s反转+10s再反转=观众眩晕弃剧）
失败模式：
  × 反转=一句话解释（"原来她是假死"说破=悬念全死）
  × 反转方向与钩子无关（观众感到被骗）

■ 卡位3：15秒爆点（10-25s，峰值帧落15-20s）
功能：全集第一次爽感兑现，决定"要不要追下一个"
公式：蓄力(3-4镜) → 爆发(1镜命中帧) → 哗然(1镜反应帧)
  ——即三连拆结构，与生成检查与规避库.txt SECTION:A·打斗拆镜规则同源
内容要求：
  ① 强度=全集最大爆点的60-70%
    ★不许超过——15秒就扔王炸=后面全程无牌
  ② 必须是"小打脸/小揭露/小胜利"，主角必须赢这一局
  ③ 爆点后跟1镜赏爽帧（全场哗然/反派吃瘪特写）
音效联动：消耗全集"爆点型音乐"配额第1次（全集≤3次）
失败模式：
  × 15s还在念背景（"我爸是沈建国……"=死亡节奏）
  × 爆点靠反派降智（爽感虚假，弹幕骂街）

■ 卡位4：30秒留坑（25-35s）
功能：埋下"本集必须看完"的核心问题，为B段供燃料
公式：新信息入场 → 指向更大未知 → 主角立Flag
示例：灵堂闹剧刚平，管家递上亲子鉴定——
      "老爷，大小姐的血样……对不上。"
内容要求：
  ① 坑必须在本集结尾半炸（给答案的一半）
  ② 坑指向本集中段冲突升级（与主线无关的支线坑=水分）
  ③ 配台词标志物：Flag句（"三天之内，我要沈家——"）
失败模式：
  × 坑太小（"她会不会生气"≠坑；"遗嘱是真是假"=坑）
  × 只埋不炸（本集尾无半兑现=失信预演）

【四档·集长适配表】
60s集 ：3s钩 → 10s反转 → 20s爆点 → 35s留坑 → 尾钩
90s集 ：3s  → 10s      → 15-20s   → 30s      → 尾钩（标准）
120s集：3s  → 10s      → 18s       → 35s → 60s二次爆点 → 尾钩
180s集：3s  → 10s      → 20s       → 35s → 60s/120s双峰 → 尾钩
★通则：四档锚点占总时长比例恒定——5% / 12% / 25% / 40%（±5%）
  集越长，坑后燃料段越长，但四档锚点位置不变

【四档连贯性校验】
钩(疑问)→反转(升级疑问)→爆点(兑现一半)→留坑(新疑问)
四者必须同一条因果链，禁止四段各说各话
一句话校验法："因为[钩]，没想到[反转]，所以[爆点]，但[坑]"
  ——串不通=四档断裂，重写

══════════ SECTION:S3-集尾留钩公式 ══════════
第三域｜集尾留钩四公式（最后10-15秒）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【集尾钩三级体系】（与多集规划库对齐）
一级·事件钩（强）：新事件/新人物/新反转炸入 → 大节点集专用
二级·情感钩（中）：关系变化/抉择悬置 → 感情线集
三级·悬念钩（常）：信息缺口/半句话 → 常规集标配
规则：付费点/季中/季末必须一级钩+三级钩叠加；
  ★一级钩连用≤2集（强钩通胀=观众麻木）

■ 公式1：半句钩（三级）
结构：关键台词说半句 → 强制打断 → 切黑
时间分解：蓄力(尾15s起5s) → 半句出口(2s) → 打断(0.5s) → 定格(2s)
台词公式：[主语]+[半句]+"——"（破折号=强制切断符）
打断方式分级：
  L1环境打断（电话铃/开门）→ L2人为打断（捂嘴/抢纸）
  → L3暴力打断（车祸/晕倒/枪响）
示例：
  "其实你的亲生父亲是——"（忙音）
  "遗嘱上写的名字是——"（纸张被一把抽走）
禁忌：半句内容下集必须兑现（见第四域），★空头半句=信任崩塌

■ 公式2：宣告钩（二级）
结构：立战书式宣言 → 目标+期限 → 定格
时间分解：静场(3s) → 宣言(3s) → 对方反应帧(2s) → 定格(2s)
台词公式：[期限]+[目标]+[代价]三要素齐全
示例：
  "三天后股东大会，沈家吃下去的，连本带利吐出来。"
  "下月十五，我亲自登门——娶她，或者，踏平谢家。"
适用：打脸文/男频/大女主（观众带"期待兑现"的心情追剧）
禁忌：宣告目标必须≥本集已展示难度（宣告更小的事=泄气）

■ 公式3：惊变钩（一级）
结构：日常假象 → 最后一镜惊变 → 戛然而止
时间分解：日常感(7s) → 惊变帧(1s) → 死寂反应(2s) → 切黑
设计要点：惊变前的"日常感"越稳，惊变越炸——先给安全感，再抽走
示例：
  团圆饭刚举杯，门开了——"死了三年"的大哥站在门口
  签字笔落下的瞬间，会议室大屏亮起：她的全部真实档案
适用：付费卡点集/季末/大节点
禁忌：惊变必须是"已埋伏笔的意外"——
  前文没提过的大哥=机械降神，弹幕"编剧没活了"

■ 公式4：身份钩（一级）
结构：尾帧揭露隐藏身份的一角 → 本人不知/全场已知（信息差）
时间分解：悬念物特写(3s) → 身份碎片显现(2s) → 知情者反应(2s) → 定格
示例：
  她摘簪盘发——后颈凤凰胎记，和遗诏图样一模一样
  黑衣人摘下面具，竟是每天给女主送早餐的保安
适用：马甲/悬疑/权谋
禁忌：只给"碎片"不给"全景"——说破=悬念死亡

【集尾钩选型矩阵】
常规集（占60-70%）→ 半句钩/宣告钩（三级为主）
情感节点集        → 宣告钩情感变体（告白被打断/诀别宣言）
付费点集          → 惊变钩（必须）+ 半句钩叠加
季末/大结局前     → 身份钩+惊变钩双叠

【集尾钩验收三问】
① 看完尾帧，观众是否有一个"必须知道答案"的问题？
② 这个问题是否明确指向下集前30秒？（指向不明=钩飘）
③ 钩子强度是否匹配节点等级？（付费点用三级钩=付费率自杀）

第四域｜跨集钩子兑现规则
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【总公式】
上集钩 → 下集前30s兑现50% → 同场景再深化出更大的坑 → 本集尾新钩接力
钩子不是"还掉的债"，是"利滚利的贷"——每次兑现必须产生新利息

■ 规则1：30秒半兑现铁律
上集尾钩承诺的问题，下集前30秒必须给出50%答案
各型兑现50%的标准：
  半句钩："你父亲是——"→ 给姓氏/照片一角/知情人登场
    （给全名+往事全交代=100%兑现=坑死）
  宣告钩："三天踏平谢家"→ 展示备战/第一步行动已出
  惊变钩："死三年的大哥回来了"→ 确认真人+第一句信息量台词
  身份钩："胎记和遗诏一样"→ 已有人开始查/知情人动杀心
失败模式：
  × 下集开头装没事（钩失信，弹幕"就这？"）
  × 开头100%兑现（坑死，观众"看完了，弃剧"）
  × 用旁白/闪回糊弄（兑现质量：画面＞台词＞旁白）

■ 规则2：再深化（兑现处必须挖新坑）
兑现50%的同一镜或下一镜，必须抛出更深的新变量
公式：旧答案(50%) + 新变量 = 旧坑变浅，新坑更深
示例：
  兑现：亲子鉴定确认知微非亲生（50%）
  新变量：鉴定医师当晚失踪——唯一知道真千金是谁的人，没了
时间位置：下集30s兑现点±10s内完成再深化
检验标准：兑现后观众心中的问题数量 ≥ 兑现前
  （问题只增不减=留存引擎永动）

■ 规则3：新旧钩接力表
任意时刻在飞钩子=2-3个（1个=单线乏力，≥4个=观众记不住）
接力节奏：
  钩A（上集尾）→ 本集前30s半兑现 → 转中长线
  钩B（本集30s坑）→ 本集尾半炸
  钩C（本集尾新钩）→ 接力下集
生命周期：短线钩1-2集 / 中线钩3-5集 / 长线钩贯穿全剧
  （身世之谜/终极仇人——最后一集才许兑现）

■ 规则4：钩子台账（每集末必更新，并入episode-planning.md）
| 钩号 | 类型 | 埋设集 | 承诺内容 | 计划兑现集 | 状态 |
状态值：在飞 / 半兑现 / 已兑现 / ★已失信（出现即整改）

■ 规则5：失信红线（触犯任一条，流失30%+观众）
  × 同一钩子悬空>5集无任何推进
  × 兑现与承诺不符（"你父亲是——"→"是个好人"，零信息量）
  × 用"做梦/误会"回收钩子（欺骗式兑现=弃剧榜第一名）
  × 新集开头重复上集尾帧>8s（水时长=划走率峰值点）

■ 规则6：钩爆守恒（全集强度分账）
单集爽感总账：开篇钩+15s爆点+中段爆点+集尾钩 = 恒定值
分配原则：
  付费点集：爆点70% + 钩30%（当场爽够，值回付费）
  常规集  ：爆点40% + 钩60%（留人为主，持续追更）
  ★开篇钩>本集最大爆点=头重脚轻（骗进来，失望加倍）

SECTION:B-爽点节奏

我先搜一下当前爆款短剧的爽点结构与付费节奏实操资料，再结合你的剧集体系做全量拆解。

# 爆款爽剧·剧情结构与爽点节奏【全量提词参数拆解】

> 行业共识锚点：爆款短剧黄金法则 = **3秒钩住人、6秒进冲突、10秒抛悬念**（[短剧编剧黄金手册](https://zhuanlan.zhihu.com/p/2000551987486418463)）；平台新规要求**前30集至少2个关键付费卡点，且集与集之间钩子埋卡、情绪高潮**（[番茄新规解读](https://zhuanlan.zhihu.com/p/1938360551085413868)）；男频核心套路已被验证为"**反派反复嘲讽陷害→主角反复打脸**"（[娱乐资本论·男频编剧访谈](https://zhuanlan.zhihu.com/p/10342076466)）。以下为13项参数逐项拆解：**定义 → 时间轴量化 → 写法模板 → 参数写法 → 避坑**。

---

## 1️⃣ 竖屏短剧三秒钩子

**定义**：决定生死的前3秒，必须完成"强刺激事件+信息差+疑问"三件套，让观众产生"不看完不舒服"的悬置感。

**6大钩子类型词库**：

| 类型 | 触发句式/画面 | 示例（隐门系） |
|---|---|---|
| 反常冲突钩 | 违背常理的动作 | 外门弟子一脚踹飞长老 |
| 身份倒挂钩 | 低位者做高位事 | 扫地杂役坐在宗主位上啃鸡腿 |
| 悬念提问钩 | 台词直接抛问题 | "你们说，宗门最强的为啥是条秃毛狗？" |
| 危机压顶钩 | 死亡/毁灭倒计时 | 护宗大阵碎裂，万人压境 |
| 奇观冲击钩 | 超大视效/巨物 | 万剑悬空对准一只吉娃娃 |
| 情绪炸点钩 | 极端表情+极端台词 | 女主一巴掌+一句"这婚，我退了！" |

**参数写法**：
`【钩子参数】类型：身份倒挂钩｜信息差：观众不知主角隐藏身份｜画面：大特写颜艺+破格占比60%｜台词≤12字抛悬念｜时长≤3秒｜禁：铺垫、风景空镜、片头logo`
**避坑**：钩子≠剧透——只给"果"不给"因"，原因必须拆到后文分批发放。

---

## 2️⃣ 每集开头强刺激设计

**定义**：3秒钩子之后到第10秒的"二次锁定"，用升级版冲突防止钩子后流失。

**时间轴量化**：
- **0-3秒**：钩子（见上）
- **3-6秒**：冲突具象化——反派登场施压/危机升级（谁、要什么、威胁什么）
- **6-10秒**：悬念点题——抛出本集核心问题，同时主角做出"反常反应"（不怕/笑了/摸鱼）

**参数写法**：
`【开头参数】3-6秒：反派压迫事件×1（台词≤15字含威胁）｜6-10秒：主角反常反应+内心独白点悬念（≤15字）｜情绪曲线：压迫→反常松弛（制造期待差）`
**避坑**：开头10秒内**禁止回忆杀、禁止世界观解说**，信息全靠冲突动作带出。

---

## 3️⃣ 付费点前置（卡点设计）

**定义**：付费墙所在集必须以"最大悬置"收尾，且付费后的第一集开头立刻兑现+再埋新钩。

**量化规范**：
- **卡点位置**：第8-12集设首卡（免费试看区末端），之后每5-8集一卡；**前30集至少2个大卡**（与平台新规一致）。
- **卡点情绪强度**：必须是全集情绪峰值的120%——即"峰还没爬到顶就切断"。
- **卡点三大母题**：身份即将揭露（差一句说破）/ 杀招即将落下（差0.5秒命中）/ 真相即将曝光（证据举起未亮）。

**参数写法**：
`【付费卡点参数】本集为付费卡点集｜集尾停在"身份揭露前1句"｜反派台词说到半句切断："你就是当年那个——"｜画面：所有人瞳孔地震大特写定格0.5秒｜下集开头3秒内必须兑现揭露+立刻埋新危机`
**避坑**：卡点前3集就要蓄能（连续小爽点喂投），卡点处忌用"梦境/假死"类廉价悬置，会掉充值率。

---

## 4️⃣ 反转节奏

**定义**：预期违背的密度与间隔控制。

**量化节奏**：
| 体量 | 小反转 | 中反转 | 大反转 |
|---|---|---|---|
| 60-90秒单集 | 每15-20秒1个 | 每集1个 | 每3-5集1个 |
| 位置 | 段落衔接处 | B段高潮位 | 集尾卡点 |

- **反转三阶公式**：铺垫（让观众确信A）→ 误导（强化A的证据）→ 颠覆（真相是B，且B早已埋伏笔）。
- **伏笔回收率**：埋3个必须炸2个以上，哑弹超过1个观众会出戏。

**参数写法**：
`【反转参数】本镜为大反转帧｜前置铺垫：第X镜/第X集已埋伏笔（写明）｜误导信息：反派自认稳赢的台词｜颠覆方式：主角亮出隐藏底牌｜画面：时间静止帧构图+反派表情崩坏大特写`
**避坑**：单集反转≤3次，超过会"反转疲劳"；每次反转后必须给2-3秒观众消化帧（反派/路人震惊反应）。

---

## 5️⃣ 打脸节奏

**定义**：短剧核心爽点的工业化流水线——反派欺压值与主角反击值的精确配比（男频90%内容为"嘲讽陷害→打脸"循环，[来源](https://zhuanlan.zhihu.com/p/10342076466)）。

**五步标准流程（绑定时间轴，以60秒集为例）**：
1. **蓄（0-10秒）**：反派嘲讽+围观起哄，欺压值拉满（越具体越狠：踩手、泼茶、辱骂家人）
2. **压（10-25秒）**：主角隐忍或"看似认怂"，观众憋屈值累积
3. **引（25-35秒）**：反派加码作死，自己把脸伸过来（"有本事你打我啊"）
4. **爆（35-50秒）**：一击打脸——物理（一巴掌/一招秒）+ 身份（亮底牌）双爆点
5. **赏（50-60秒）**：围观反转站队+反派跪地求饶+主角云淡风轻金句

**参数写法**：
`【打脸参数】流程：蓄→压→引→爆→赏｜欺压值：语言羞辱+物理侮辱双叠加｜打脸帧：巴掌命中定格0.3秒+冲击线+反派面部畸变颜艺｜金句≤10字："你也配？"｜围观反应帧≥2镜`
**避坑**：压抑段不得超过全集50%——憋太久观众先跑了；打脸后必须"踩到底"（追加一次补刀），爽感才封顶。

---

## 6️⃣ 误会—揭露—反杀结构

**定义**：三段式经典骨架，适用于30-80集体量的主线单元。

**结构量化**（以10集为一单元）：
| 段落 | 集数 | 任务 | 关键指标 |
|---|---|---|---|
| 误会 | 1-4集 | 主角被冤/被错认/被错怪，所有人不信他 | 误会必须有"证据"支撑（伪造的信物/目击），不能靠全员降智 |
| 揭露 | 5-7集 | 线索逐层剥开，先揭给反派看（恐惧），再揭给大众（震惊） | 揭露顺序：观众先知道→反派知道→全世界知道，三级信息差 |
| 反杀 | 8-10集 | 主角以误会中积累的资源/身份/力量，一击清算 | 反杀手段必须与当初被冤的罪名形成镜像（以彼之道） |

**参数写法**：
`【结构参数】本集处于"揭露段"第2环｜信息差等级：观众已知/反派刚知｜揭露道具：当年证物（关键道具高亮参数）｜镜像反杀预埋线：写明与第X集冤案的对应关系`
**避坑**：误会段严禁主角有机会一句话解释却不说（观众会骂强行），必须设计"解释了也没人信"的封嘴机制。

---

## 7️⃣ 情绪压迫—释放结构

**定义**：爽剧的底层生理机制——压迫值积累 vs 释放值爆发的波形管理。

**波形量化**：
- **压迫期**：连续2-4镜施压（每镜压强递增20%），总时长≤全集45%
- **极限点**：全剧最憋屈的一镜——主角最惨时刻（被踩到泥里），观众愤怒值峰值
- **释放期**：爆发帧+连踩3次爽点（打脸→亮身份→收小弟/美人），释放强度≥压迫值的150%
- **喘息期**：释放后1-2镜轻松日常/喜剧调剂（刀乐卖萌），为下一波蓄能

**参数写法**：
`【情绪波形参数】本集波形：压迫3镜（压强+20%递增）→极限帧（主角跪地泥水中，光比8:1冷蓝）→释放爆发帧（金光炸开暖调切入）→连踩爽点×3→喘息帧（刀乐丑萌发抖，喜剧）`
**避坑**：禁止连续两集纯压迫无释放（弃剧率最高区）；每集至少给1个"最小释放"（一句金句反怼也算）。

## 1️⃣3️⃣ 悬疑留钩方式

**定义**：让观众"必须看下一集"的信息缺口工程。

**8大留钩类型词库**：
| 类型 | 写法 | 示例 |
|---|---|---|
| 半句话钩 | 关键台词说一半切断 | "其实你的真实身份是——"（切黑屏） |
| 门后钩 | 开门/掀盖动作做完，不给结果 | 推开密室门，画面切走 |
| 第三者钩 | 主角不知道的危险正在逼近 | 主角安睡，黑影破窗（观众知道=焦虑） |
| 倒计时钩 | 明确deadline悬置 | "三日后问斩"，刑场已搭好 |
| 证据钩 | 关键证物出现未公开 | 镜头扫过桌上的玉佩（观众认出=仇人信物） |
| 表情钩 | 知情人意味深长的表情 | 长老看着主角背影冷笑 |
| 逆转钩 | 盟友黑化瞬间 | 最信任的师兄暗中捏碎传讯符 |
| 问题钩 | 直接抛悬念台词 | "死人……怎么会回来？" |

**参数写法**：
`【留钩参数】类型：半句话钩+表情钩双叠加｜信息缺口：写明观众"知道什么/不知道什么"｜钩子的兑现集数：下集前30秒必须半兑现（给一半答案+新缺口）`
**避坑**：钩子必须"连环保"——旧钩兑现的同时新钩已埋下；纯吊胃口不兑现超2集=观众流失。

## 1️⃣4️⃣ 集尾 Cliffhanger 设计

**定义**：集尾3-8秒的"强制续看"装置，是完播率与付费率的双重引擎（平台要求"集与集之间钩子埋卡、情绪高潮"，[来源](https://zhuanlan.zhihu.com/p/1938360551085413868)）。

**四档强度分级**：
| 档位 | 适用位置 | 设计 |
|---|---|---|
| 一级·微钩 | 日常集结尾 | 新人物登场剪影/一句反常台词 |
| 二级·中钩 | 剧情推进集 | 危机降临瞬间/秘密被撞破前一秒 |
| 三级·大钩 | 每5集 | 杀招出手未命中/身份即将说破/背叛揭露 |
| 四级·付费卡钩 | 付费墙集 | 全集最大情绪峰值120%处切断（见参数3️⃣） |

**标准结构（集尾8秒拆解）**：
- **-8~-5秒**：突发事件启动（门被踹开/剑光袭来/来人开口）
- **-5~-2秒**：情绪拉满——所有在场者反应快切（3-4个大特写快切，每切0.5秒）
- **-2~0秒**：定格——停在最高点：反派半句话/杀招距脸0.01米/主角意味深长一笑
- **定格帧参数**：时间静止+心跳音效骤停+黑屏字幕"下集"或直接切黑

**参数写法**：
`【集尾钩参数】档位：三级大钩｜-8~-5秒：大殿门炸开，神秘人逆光剪影登场｜-5~-2秒：长老/反派/主角三方大特写快切×3｜定格帧：神秘人台词半句"苏辰……我找了你十年——"切黑｜音效：心跳声骤停+0.5秒静默`
**避坑**：定格帧绝不能停在"情绪回落区"；切黑后**严禁接片尾曲缓冲**，直接跳转下一集预览（平台自动连播逻辑）。

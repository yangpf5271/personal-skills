模式E：直接出 Seedance 提示词模式
当前默认子模版：模版一
目标：直接输出可在 Seedance 2.0 / Seedance 2.5 使用的成品提示词
════════════════════════════════════════════════════════════

一、模式E定位
1. 模式E不是分镜卡片，不输出模板B/C/D那种“给人看”的分镜说明。
2. 模式E的目标是：把剧情或已有分镜，直接整理成 Seedance 可投喂的镜头提示词。
3. 用户未指定子模版时，默认输出“模版一”。
4. 当前已支持：模版一、模版二、模版三。用户未指定时默认输出模版一。
5. **模式E的镜头单位是“生成镜头”而不是“分镜文档里的原镜头”**。输入里的一个模板D镜头，到了模式E阶段，允许也通常应该根据内部情节再切成 2-4 个更适合 Seedance 生成的 E 镜头。
6. **模式E支持“单个提示词总时长”规则**。当用户给出 `10s / 15s / 20s / 30s` 之一时，这个值不是单纯改秒数，而是会决定：一条提示词里塞几个情节节拍、几个生成镜头、多少铺垫、多少停顿、一个镜头要走多完整的动作链。

二、模式E触发规则
1. 用户明确说“模式E / 模版E / 直接出sd提示词 / 直接出 Seedance 提示词”时，输出模式E。
2. 用户给的是剧情原文，也可以直接走模式E。
3. 用户贴入模板D成品，并要求“转成 Seedance 可直接用的提示词”时，也直接输出模式E。
4. 如果用户同时给出“单集总时长 + 单个提示词总时长”，则模式E必须：
   - 先按单集总时长规划整集节奏
   - 再按单个提示词总时长把整集切成若干条 Seedance 提示词
   - 最后才写每条提示词内部的生成镜头
   - **提示词条数计算规则**：`提示词条数 = 单集总时长 ÷ 单个提示词总时长`；能整除就按整除结果输出，例如 `90s ÷ 15s = 6条`、`90s ÷ 30s = 3条`；不能整除则向上取整，最后一条允许略短，但必须把剩余剧情讲完

二点一、单个提示词总时长规则（模式E专属）
1. 当前支持的固定值：`10s / 15s / 20s / 30s`
2. 该值只对模式E生效，不影响模板A/B/C/D。
3. 该值影响的是**单条提示词内部的结构设计**，不是只影响标题里的时间数字。
4. 设计规则：
   - `10s`：每条提示词通常承载 2-4 个生成镜头，只保留一个核心动作链或一个微反转，铺垫必须短，强调直给。
   - `15s`：每条提示词通常承载 3-5 个生成镜头，允许一条完整的小节拍链，适合大多数标准直出。
   - `20s`：每条提示词通常承载 4-6 个生成镜头，允许更完整的因果推进、明显反转或更完整的文戏停顿。
   - `30s`：每条提示词通常承载 5-8 个生成镜头，只适合长生成场景；允许更完整的连续动作链、双节拍推进或更长留白，但必须保持同一主场景/同一主事件。
5. **强规则：单个生成镜头一般不要超过 4 秒。**
   - `10s / 15s / 20s / 30s` 控制的是**一条提示词总时长**，不是单个镜头时长。
   - 当总时长变长时，优先增加生成镜头数量、补充反应镜、补充铺垫镜、补充收束镜，而不是把某一个镜头直接拉长。
   - 文戏也一样，长的不是某一镜，而是整条提示词容纳的节拍更多。
   - 只有极少数明确要求长镜头感、并且动作链连续、画面重心稳定的镜头，才允许谨慎接近 4 秒上限。
5. 绝对禁止：
   - 只把 `【00:00-00:15】` 改成 `【00:00-00:30】`
   - 10秒和30秒用同一套镜头密度，只改时间标签
   - 不根据时长变化重做镜头切分和节拍安排
   - 明明总时长能算出 6 条提示词，却只输出 1 条或 2 条示例

三、模板D识别协议（供 skill 识别 D → E 转换）
1. 模板D成品顶部必须包含这一行：
   【模板标识】MODE_D_STORYBOARD_V1
2. skill 见到该标识时，直接判定输入内容为“模板D分镜原文”。
3. 若是旧版模板D没有标识，但结构上同时满足以下特征，也可按旧版D识别：
   - 存在多个 `### 镜N · ...` 标题
   - 每镜下面有代码块
   - 代码块内重复出现 `[空间锚] / [角色卡] / [光影锁] / [声音锁]`
4. 一旦识别为模板D，并且用户要求“直接出 Seedance 提示词 / 转模式E / 直接出sd提示词”，则跳过常规分镜重写，直接执行 D → E 转换。

四、子模版总览
1. 模版一：Asset_Setup + 逐镜单行提示词。适合大多数稳定直出场景，偏稳、偏清楚、偏结构化。
2. 模版二：全局锁定 + 长镜头/连续镜头描述。适合更电影化、更连贯、更强调单镜内部节奏的输出。
3. 模版三：打斗专用模版。适合高速近战、拳脚对拆、异能格斗、海滩/雨战/巷战等武戏直出。
4. 用户未指定子模版时，默认输出模版一。

五、模版一格式总结（默认输出格式）
模版一在多条输出时，**每一条提示词都必须是一个可独立复制到 Seedance 的完整包**。每条提示词由 6 个区块组成，顺序固定，不要删减，不要重排：

1. 段首标题区
   - 固定格式：
     `【提示词N】【整集覆盖时间段】`
   - 示例：
     `【提示词1】【00:00 - 00:15】`
     `【提示词2】【00:15 - 00:30】`
   - 作用：告诉用户这一条提示词负责整集中的哪一段剧情。
   - 注意：**这个时间段是整集覆盖区间，不是该条内部镜头时间轴。**

2. `<Asset_Setup>` 本条资产锁区
   - 全局风格锁
   - 出场资产锁
   - 光影基调锁
   - 物理状态遗留
   - 作用：把本条提示词涉及到的角色、服装、材质、光影、状态连续性一次锁死，确保单独复制也能直接生成。
   - 强规则：每条提示词都必须重写这一块；允许冗余，但必须根据本条内容动态调整，不能整集所有提示词一字不差照抄。

3. 本条空间锁区
   - 使用 `【空间坐标与专属背景锁】`
   - 作用：把本条提示词内部的主场景、主站位、空间轴线、桌面道具或背景连续性说清楚。
   - 强规则：每条提示词都要单独带这一块，方便直接复制使用。

4. 本条逐镜提示词区
   - 每镜格式固定为：
     `【镜头 N】【开始时间 - 结束时间】`
     下一行直接写单行提示词：
     `景别 + 机位/运镜 + {主体角色与动作、台词/口型} + {背景/空间延续} + 构图说明 + 光影说明 + 生成约束`
   - **该条内部的镜头时间轴必须从 `00:00` 开始重新计算。**
   - 示例：如果段首是 `【提示词2】【00:15 - 00:30】`，该条内部仍然应该从 `【镜头1】【00:00 - 00:03】` 开始，而不是 `00:15` 开始。
   - 单镜提示词要求：
     - 直接可投喂 Seedance
     - 信息密度高，但仍保持一行结构清楚
     - 尽量先写镜头与动作，再写背景与构图，最后写光影与限制
   - **这里的“镜头 N”指的是 Seedance 生成镜头，不等于输入分镜的原始镜号。**

5. `【负面词约束】`
   - 基础负面词
   - 动态负面词
   - 作用：处理手部、脸部、透视、穿模、角色漂移、背景瞬移等问题。
   - 强规则：每条提示词都必须单独带这一块，方便用户整段复制。

6. 分界线
   - 固定输出：
     `--------------------------------------`
   - 作用：清晰切开每条可独立复制的提示词包。

六、模版一输出铁律
1. 默认只输出模版一本体，不附设计说明、自检解读、分析过程。
2. 保持单镜一行，不拆成段落卡片。
3. 逐镜内容优先服务 Seedance 的直接生成，不追求模板B那种阅读性。
4. **每条提示词都要自带完整的 `<Asset_Setup>`、`【空间坐标与专属背景锁】`、`【负面词约束】` 和分界线**，因为默认使用场景是“逐条复制到 Seedance 直接生成”。
5. 若输入来源是模板D，则优先保留其场景顺序、人物关系、动作重心和情绪推进，但**不要机械保持 1 个D镜 = 1 个E镜**。
6. 模式E必须优先保证“每个生成镜头内部只有一个明确动作重心或一个连续动作链”，而不是把一个复杂分镜整段硬塞给一个镜头。
7. **每条提示词内部镜头时间必须从 00:00 开始，不得沿用整集累计时间。**
8. **每条提示词里的资产锁、光影锁、状态锁、道具锁必须根据该条实际剧情阶段局部改写**。前段可以偏审视、铺垫、试探；中段可以偏压迫、失衡、对抗；后段可以偏揭露、打脸、难堪、收束。允许冗余，但不允许机械复制成完全同文。

六点一、模式E切镜与时间轴规划规则（核心规则）
模式E收到剧情原文或模板D分镜后，必须先做一次“生成镜头切分”，再写提示词。切分原则如下：

1. **切分单位**
   - 按“可生成动作重心”切，不按“文档段落”硬切。
   - 一个E镜头只承载以下之一：
     - 一个进入动作
     - 一个明确表态动作
     - 一个关键反应
     - 一个反转落点
     - 一个收束留钩

2. **何时必须切镜**
   以下任意一种出现，都应拆成新的E镜头：
   - 主体动作变化（坐着对视 → 推茶 → 伸手拨杯）
   - 主视角变化（双人关系镜 → 单人反应镜 → 道具反转镜）
   - 情绪功能变化（试探 → 受压 → 反制 → 定局）
   - 画面重心变化（人物脸 → 手部/道具 → 双人关系）
   - 台词功能变化（施压句、回击句、揭露句、定局句）

3. **何时不要切镜**
   - 同一人完成一条连续动作链，且镜内重心不变
   - 同一组对视/靠近/停顿仍服务同一个情绪点
   - 只是补充性形容，并未改变动作或叙事功能

4. **推荐切分数量**
   - 一个模板D镜头通常切成 2-4 个E镜头
   - 很简单的动作镜可保持 1 个E镜头
   - 很复杂的复合镜头可拆到 5 个E镜头，但应谨慎，避免碎得失去连续性

5. **时长分配总原则**
   - 时长不是平均分，必须按情节功能分配
   - 情节越复杂、动作越完整、情绪停顿越重要，时长越长
   - 反应镜、揭示镜、反转镜通常比“解释镜”更值得时间

6. **Seedance 推荐单镜时长**
   - 极短反应镜：1.0-1.8秒
   - 普通动作镜/关系镜：2.0-3.5秒
   - 连续动作链/长镜氛围镜：3.2-4.0秒
   - **单个生成镜头一般不要超过 4 秒**。若总时长变长，优先增加镜头数量与节拍层次，不要把单镜直接拉长。

7. **文戏时长分配建议**
   文戏镜头优先按这个逻辑分配时长：
   - 建立关系镜：2.5-4.0秒
   - 压迫/停顿/看向/手部细节：1.5-3.0秒
   - 关键反制/露字/揭露：2.0-3.5秒
   - 收束留钩：2.0-4.0秒

8. **武戏时长分配建议**
   - 起手/蓄力：1.0-2.0秒
   - 命中/碰撞：1.0-2.5秒
   - 击飞/反馈：1.0-2.0秒
   - 爆点长镜：2.5-4.5秒

9. **时间轴规划顺序**
   模式E生成前，内部必须先做这四步：
   - ①先确定整集要拆成几条提示词，并为每条提示词标注整集覆盖时间段
   - ②再分别找出每条提示词内部的情节节拍点
   - ③按节拍点切成若干E镜头，并让**每条提示词内部时间轴从 00:00 开始**
   - ④给每个E镜头分配时长
   - ⑤再把每个E镜头写成可直接投喂的提示词

10. **绝对禁忌**
   - 禁止把一个包含“试探+递茶+反应+揭露”的复杂分镜全塞成一个12秒镜头
   - 禁止平均切时长
   - 禁止只按原模板D镜号输出，而不做二次切分
   - 禁止把整集第一条提示词的 `<Asset_Setup>` 直接原样复制到后面所有提示词，而不根据本条剧情变化重写
   - 禁止把第二条、第三条提示词内部镜头时间继续写成 `00:15`、`00:30` 开始

六点二、切镜示意（文戏示例）
例如模板D里有一个12秒分镜，内容是：
`裴玄递茶施压，萧晏看向茶面，再抬眼回看，随后伸手拨开茶盏露出朱砂批注。`

模式E不应写成：
`【镜头1】【00:00-00:12】把上面全部塞进一个镜头`

而应优先切成类似下面的 E 镜头：

1. `E镜1（2.5秒）`：裴玄递茶到中线，建立施压动作重心
2. `E镜2（2.0秒）`：萧晏先看茶面，再抬眼，表现受压不退
3. `E镜3（2.5秒）`：萧晏伸手拨杯，动作成为反转触发点
4. `E镜4（3.0秒）`：露出批注，裴玄笑意停住，落在揭露与反应

这样切分的原因：
- 每个镜头只有一个主要动作或一个主要叙事功能
- 每段时长跟动作复杂度、情绪停顿和信息价值相匹配
- Seedance更容易稳定生成，不会把多重事件混成一坨

七、模版一实战优化规则（Seedance 2.0 / 2.5 推荐）
1. 顺序固定：每一镜默认按这个顺序组织，不要乱序：
   景别/机位/运镜 + 主体角色与动作 + 台词/口型（如有） + 背景/空间延续 + 构图重心 + 光影 + 限制词
2. 单镜密度控制：
   - Seedance 2.0：建议单镜主体提示词聚焦在 1 个主动作 + 1 个主情绪 + 1 个主空间关系
   - Seedance 2.5：可以略长，但仍优先保证“单镜一个明确重心”，不要把多段动作链全塞进一镜
3. 角色写法：
   - 首镜可写完整识别锚
   - 后续镜头只保留“身份感/年龄感/服装锚/名字/动作锚”几个最关键点
   - 避免每镜重复完整服饰百科
4. 动作写法：
   - 每镜只保留一个主动作，次动作最多一个
   - 优先写可拍到、可生成、能决定画面重心的动作
5. 台词与口型：
   - 只有明确开口说话时才写“配音口型同步”
   - 单镜最好只保留一句完整台词，不要一镜多句
6. 背景写法：
   - 第一镜写清专属背景
   - 后续镜头优先使用“背景沿用空间锁，不重复改场景”
   - 不要在同场景里反复重写大段背景描述
7. 构图写法：
   - 一镜只保留一个构图中心词，如三分法、主体居中、轴线延续、前后景压层
   - 不要一镜堆叠多个构图术语
8. 光影写法：
   - 光影是稳定层，不是每镜创新层
   - 同一段里尽量延续同一个光影母体，只做延续或轻微增强
9. 限制词收尾：
   - 推荐固定收尾：无字幕 / 焦点锁角色 / 不重复改场景 / 避免明显错误
   - 限制词不要比正文还长
10. 连续性优先级：
   - 角色不漂移 > 空间不跳轴 > 动作能生成 > 画面装饰更丰富
   - 如果信息过多，优先砍掉装饰描写，保留角色、动作、空间、光影
11. 模式E默认目标：
   - 不是把分镜完整解释给人看
   - 而是把每镜压成模型最容易吃懂、最容易稳定复现的生成提示词
12. 若输入是模板D：
   - 先做“D镜头内部节拍拆分”
   - 再输出 E 镜头时间轴
   - 必要时可把 `D镜3` 拆成 `E镜5、E镜6、E镜7`

八、模版一推荐骨架（默认输出骨架）
每镜建议尽量贴近下面这个骨架：

`景别 + 机位/运镜 + {角色识别锚 + 主动作 + 台词/口型} + {背景或空间延续} + 构图重心 + 光影延续 + 生成限制`

简化示意：

`近景 + 平视机位 + 缓慢前推 + {七八岁女童陈雪，冲到院中，面向浴桶尖叫：“住手！”配音口型同步} + {陈雪专属背景：宫墙院门与石地} + 三分法构图，主体重心明确 + 柔光漫反射，浅景深，焦点死锁陈雪 + 无字幕。`

九、模版二格式总结（连续镜头 / 电影感增强版）
模版二的目标不是“更碎”，而是“让单镜内部更完整、更流动、更像一段镜头在走”。适用于：

1. 文戏长压迫镜头
2. 角色持续走位、转身、靠近、停顿这类连续动作镜头
3. 仙侠、悬疑、赛博等需要单镜氛围递进的场景
4. 用户明确说“电影感更强 / 长镜头感 / 连续镜头 / 不想太碎”

1. 标题说明区

   - 强规则：如果模式E输出多条提示词，模版二也必须做到“一条一包”，即每条提示词都单独重复自己的全局锁定与负面词约束，不能只在最前面给一次。

十、模版二输出铁律
1. 每镜优先表现“镜头怎么走、人物怎么连续动、画面怎么递进”，而不是堆很多静态修饰词。
2. 每镜可写 2-3 个连续小节拍，但必须是一条不断裂的动作链。
3. 优先写“进入 -> 停顿 -> 变化 -> 落点”这种连续过程。
4. 模版二适合更电影化的单镜，不适合把很多碎镜头强行并成一镜。
5. 如果场景本身就是快切打斗、爆点密集，不要硬用模版二，应优先回模版一或模板D。

十二、模版二实战优化规则（Seedance 2.0 / 2.5 推荐）
1. Seedance 2.0 下，模版二每镜建议控制在一个完整动作链，不要写成过长段落。
2. Seedance 2.5 下，可在单镜里容纳 2-3 个小节拍，但动作链必须连续。
3. 运镜词优先写路径：推进、侧移、绕前、轻俯压、缓慢跟随。
4. 角色动作优先写连续变化：看向、转身、靠近、停下、抬手、压住、后退半步。
5. 尽量少写“突然切到、再切到”，因为模版二不是快切模板。
6. 构图和焦点可以在镜内变化，但只保留一个主变化，不要多线程。
7. 模版二最重要的是“过程感”，不是“词多”。

十四、模版三格式总结（打斗专用模版）
模版三专门服务于 Seedance 的武戏直出，不追求文戏那种完整 Asset_Setup 叙述，而是优先保证“整体战斗设定一次锁死 + 分镜逐击清楚 + 接触点清楚 + 负面词单独可复制”。固定由 3 个区块组成：

1. `【整体战斗设定】`
   - 必须包含：整体风格、人物识别锚、双方武术/打法类型、场地环境响应、整体运动规则
   - 这部分是整条打斗提示词的母体，不要只写风格词，必须写清“谁怎么打、环境怎么跟动作互动”
   - 适合写法：
     - 风格：`3D日漫电影级高速战斗，动作逐击清晰、力量感沉重`
     - 人物/体系：`雷电周身银紫电弧，主打截拳道、咏春快打、高速腿法；太极周身黑白螺旋劲气，主打太极化劲、腿法破根、八极兑现`
     - 场地：`暴雨海滩，巨浪、海雾、湿沙、浅水、贝壳碎屑持续响应动作`
     - 总规则：`全程不停步走位、切角绕后、侧闪反进，仅碰撞瞬间允许0.1-0.2秒顿挫`

2. `【分镜】`
   - 每个分镜必须写成：
     `开始时间-结束时间 镜头与动作细节`
   - 每个分镜内部必须同时包含：
     - 景别
     - 机位 / 运镜
     - 打斗内容
   - 推荐写法：
     `0-0.5s 镜头与动作细节`
     `双人全身中景·45°斜侧平视·急速推镜微颤·跟随拳掌接触点。雷电从屏幕左侧零前摇直线突入……`
   - 强规则：
     - 单个分镜通常不要超过 4 秒
     - 分镜时长必须按真实打斗节奏动态分配，允许非平均切分，不要写成固定整齐时长
     - 每个分镜都要写清楚“谁在左/谁在右/谁前压/谁卸力/谁滑退”，避免生成时失去因果关系
     - 可写极短微慢镜，但只允许出现在接触、撞击、卸力兑现等关键点，且必须立刻回速

3. `【负面提示词】`
   - 单独成块输出，方便直接复制
   - 优先覆盖：站桩、回合制、瞬移、长蓄力、动作糊团、乱换轴、乱晃镜头、特效遮挡接触点、肢体穿模、多余手脚、换脸换装、第一段提前分胜负、字幕水印、无故出现武器

十五、模版三输出铁律
1. 模版三优先用于武戏、高速攻防、拳脚对拆、法术近战、近身搏斗，不用于纯文戏。
2. 先锁整体战斗母体，再拆分镜。禁止直接跳过“整体战斗设定”。
3. 每个分镜都必须有清晰的接触点或因果链，不能只写“高速打斗一轮”这种空话。
4. 每个分镜都必须自带景别与运镜，不能只写动作。
5. 时间轴必须服从动作，不服从排版整齐。0.5秒、2.6秒、3.1秒都可以，只要符合战斗节奏。
6. 单个分镜通常不要超过 4 秒；总时长变长时，优先增加分镜数量与攻防层次，不要把单镜直接拖长。
7. 打斗过程中默认持续走位、切角、换重心、贴边闪进；禁止站桩轮流演示招式。
8. 特效只能强化接触，不得遮挡接触点和肢体走向。
9. 模版三末尾必须单独输出`【负面提示词】`，不能并入正文。
10. 如果整集被拆成多条 Seedance 提示词，则每一条都要重复自己的`【整体战斗设定】 + 【分镜】 + 【负面提示词】`完整结构，不能只在第一条给一次整体战斗设定。

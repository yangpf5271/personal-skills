一、模版F的定位
模版F不是分镜模板，也不是 Seedance 直出提示词模板。
模版F专门用于：从剧情、脚本、小说、文案、分镜草稿中，提取后续创作真正需要锁定的资产，并生成可直接复用的描述提示词。

适用场景：
1. 用户想先整理角色卡、场景卡、道具卡
2. 用户准备后续继续做模板D / 模板E / 图片提示词 / 视频提示词
3. 用户给的剧情很长，想先抽出核心资产，再做分镜
4. 用户要做多集连续内容，需要一套稳定的资产母表

二、模版F的输出目标
输出目标不是“名词清单”，而是“可生成、可复用、可锁定”的资产表。

每项资产至少要回答 4 件事：
1. 它是什么
2. 它在剧情里负责什么
3. 它有哪些必须稳定保留的识别锚点
4. 它的描述提示词该怎么写，后续才能直接拿去做图或做视频

三、模版F固定输出结构
必须固定输出为以下三大区块：

【人物资产】
【场景资产】
【道具资产】

每项资产建议统一使用以下字段：
- 资产名
- 功能定位
- 稳定识别锚点
- 描述提示词

其中人物资产额外强制增加：
- 固定格式输出

只要输出【人物资产】，每一个人物条目后都必须完整追加下面这段固定格式，不能省略：
左侧1/3区域为超大高清面部特写，脸部特写必须是正面特写，右侧2/3区域整齐排布角色三张全身三视图，包含角色的正面(FRONT)、侧面(PROFILE)及背面(BACK)三个维度的全身站姿视图。人物下方配有服装细节与配饰介绍展示图，整体构图工整专业，背景为纯白色背景。视觉对齐:所有角度的比例必须严格一致，确保角色身高、五官位置、服装褶皱在不同视角下完美契合。图片上不能出现任何文字。

其中场景资产额外强制增加：
- 固定格式输出

只要输出【场景资产】，每一个场景条目后都必须完整追加下面这段固定格式，不能省略：
场景按四视图格式输出，包括高角度航拍俯瞰，低角度仰视，侧面视角，反面视角。同一张图四宫格输出，画面中带文字描述视图角度。

如剧情较长、角色较多，可在每项后面增加：
- 出场关系 / 绑定对象
- 连续性提醒

四、人物资产提取规则
人物资产尽量完整提取。满足以下任一条件的人物都应提取：
1. 具名角色
2. 虽未具名，但多次出现并承担叙事功能的角色
3. 与主角关系强绑定，后续需要保持脸、发型、服装、体态连续的角色
4. 推动冲突、反转、揭露、对峙、情绪弧线的功能角色

人物提取时必须处理：
1. 合并别名、称呼、身份称谓，避免同一角色拆成多条
2. 明确主次：主角、关键配角、功能性角色分层
3. 原文没写死的细节，只能做保守推断
4. 不得把完全路人化、无功能、仅一闪而过且无连续性需求的人物强行列入

人物提示词生成优先级：
1. 年龄段 / 性别气质
2. 身份与职业功能
3. 发型、面部、体态、神情底色
4. 常驻服装基调
5. 与他人的关系感

五、场景资产提取规则
场景资产要覆盖所有需要独立锁定的主空间。满足以下任一条件的场景都应提取：
1. 剧情真实发生的空间
2. 反复出现、需要保持前后连续的空间
3. 承担关键冲突、揭露、情绪转折、高潮的空间
4. 时间、天气、光影、材质、布局特征鲜明的空间

下列情况可不单独立项：
1. 只在台词里被提及、但没有落地成画面的地点
2. 与主场景没有明显视觉差异、且不需要单独锁定的小过渡空间
3. 纯背景补白地点

场景提示词生成优先级：
1. 空间类型
2. 时代/地域/行业属性
3. 时间天气
4. 光源结构
5. 材质与陈设
6. 空间布局和镜头锚点

五点五、纯场景生成硬规则
当模板F输出场景资产时，默认优先按“可直接生成纯场景”处理，而不是写解释型文案。

必须遵守以下规则：
1. 画面中严禁出现任何人影、角色姓名、人物剪影、人物主导痕迹。
2. 场景名称必须在四个字以上，并通过修饰词增强辨识度，禁止只写“咖啡厅”“卧室”“街道”等单一名词。
3. 场景描述必须完整涵盖四大核心要素：
   - 环境类型
   - 具体时间
   - 空间氛围
   - 视觉主要特征
4. 每个场景资产都必须绑定固定四视图格式输出：
   - 高角度航拍俯瞰
   - 低角度仰视
   - 侧面视角
   - 反面视角
   同一张图使用四宫格呈现，并带有明确的视图角度文字描述。
5. 所有场景Prompt必须以：
   `不能出现其他人, 无人, 纯场景,`
   开头，并额外包含：
   `no humans, empty, landscape only`
6. 严禁写“适合都市情感对话”“适合关系反转”“电影级空间设定”“氛围很好”这类空洞说明，必须全部转译成真正可见的空间信息。
7. 场景提示词的目标是“让模型直接画出这个空间”，不是“解释这个空间在剧情里干什么”。

五点六、场景命名法则
场景名必须具备独特性，优先从以下信息中至少选两项组合：
1. 位置：靠窗 / 顶楼 / 转角 / 门厅 / 长廊 / 中庭
2. 光线：暖光 / 冷白 / 逆光 / 暮色 / 霓虹 / 晨雾
3. 材质：木质 / 金属 / 玻璃 / 石材 / 织物 / 水泥
4. 用途：相亲位 / 办公区 / 接待区 / 包厢 / 休息室
5. 时间：午后 / 深夜 / 黄昏 / 雨夜 / 清晨

可用方向示例：
- 暖光靠窗咖啡厅
- 午后木质相亲位
- 冷白玻璃会议室
- 夜雨霓虹街角店

六点五、纯场景专用输出模板
如果用户重点要的是“场景可直接生图”，可按下面格式输出：

【场景提取清单】
1. 场景全称｜核心氛围｜建议色调

【专业场景设定表】
- 场景名称：[四个字以上的独特命名]
- 画幅构图：横向 16:9 电影级场景设定图，极高画质，纯净无人的空间。
- 视图绑定：同一张图四宫格输出，包含高角度航拍俯瞰、低角度仰视、侧面视角、反面视角，画面中带明确的视图角度文字描述。
- 视觉风格：[用户指定风格]
- 场景描述：
  - 环境类型：[具体的地理/建筑空间属性]
  - 时间时刻：[精确到时段的天气与光线状态]
  - 空间氛围：[压抑/宁静/神圣/破败等视觉氛围词，但必须能落到画面]
  - 主要特征：[具体材质、核心物件、前中后景标志性元素，严禁提及角色姓名]
- Prompt (直接复制)：不能出现其他人, 无人, 纯场景, [融合全部环境细节的精简生图描述词], no humans, empty, landscape only

六、道具资产提取规则
道具不要贪多，只提关键道具。
满足以下任一条件才提取：
1. 被特写、被强调、被独立镜头看见
2. 出现次数大于 1 次，且前后需要保持一致
3. 推动剧情、制造误会、形成反转、证明身份、完成打脸的道具
4. 被角色反复拿取、佩戴、查看、递交、损坏、丢失的道具
5. 明显属于人物识别锚的一部分，例如长期佩戴的饰品、武器、旧手机、文件夹、玉佩、录音笔

默认不提取：
1. 纯背景填充物
2. 一次性出现、无剧情功能、无特写、无连续性需求的普通物件
3. 任何只是为了“凑完整”而列入的无关杂物

道具提示词生成优先级：
1. 名称
2. 材质 / 颜色 / 新旧程度
3. 尺寸或造型特点
4. 使用方式
5. 绑定人物
6. 剧情作用

七、描述提示词生成规则
模版F的“描述提示词”必须能直接用于后续创作，不得只写口号式概括。

写法要求：
1. 先抓文本明示信息，再补上下文合理信息
2. 推断只能保守，不得瞎编超出剧情的信息
3. 优先写稳定锚点，不要写空泛赞美词
4. 用“可被模型识别”的描述，不要只写抽象评价

好例子：
- 都市白领女性，27岁，长发微卷，珍珠耳坠，米白修身裙装，通勤妆精致，气质漂亮干练，前期优雅审视，后期僵硬失态
- 市中心高端西餐厅，靠窗双人桌，镜面墙，暖金吊灯，白桌布，酒杯刀叉，窗外城市夜景霓虹，轻奢而克制
- 旧款黑色手机，屏幕边角轻微磨损，低调过时，握持频繁，是角色身份误判的重要锚点

差例子：
- 很美的女生
- 很高级的餐厅
- 一个重要道具

八、连续性与合并规则
1. 同一人物在不同段落中的不同称呼必须合并
2. 同一场景在不同时间段若基础空间不变，可并入一个主场景，并在提示词中补时间变化
3. 同一道具若承担多个功能，也应保持一条资产，不要拆散
4. 若剧情里出现“旧手机 / 手机 / 黑色手机”，且明显是同一部，就合并成一个道具资产

九、模版F建议输出样式
建议尽量使用下面这种结构：

【人物资产】
1. 资产名：苏晚
- 功能定位：女主 / 相亲场中的主观察者与后续被打脸者
- 稳定识别锚点：27岁，都市白领女性，长发微卷或低扎，珍珠耳坠，精致通勤妆，米白或浅杏色修身裙装，前期优雅审视，后期错愕难堪
- 描述提示词：现代都市白领女性，27岁，长发微卷或低扎，珍珠耳坠，精致通勤妆，米白或浅杏色修身裙装，气质漂亮干练，前期优雅审视，后期僵硬失态
- 固定格式输出：左侧1/3区域为超大高清面部特写，脸部特写必须是正面特写，右侧2/3区域整齐排布角色三张全身三视图，包含角色的正面(FRONT)、侧面(PROFILE)及背面(BACK)三个维度的全身站姿视图。人物下方配有服装细节与配饰介绍展示图，整体构图工整专业，背景为纯白色背景。视觉对齐:所有角度的比例必须严格一致，确保角色身高、五官位置、服装褶皱在不同视角下完美契合。图片上不能出现任何文字。

【场景资产】
1. 资产名：高端西餐厅靠窗双人桌
- 功能定位：相亲主战场 / 打脸反转发生地
- 稳定识别锚点：市中心顶级西餐厅，靠窗双人桌，镜面墙，暖金吊灯，白桌布，酒杯刀叉，窗外城市夜景霓虹
- 描述提示词：市中心高端西餐厅，靠窗双人桌，镜面墙，暖金灯光，白桌布，刀叉酒杯，落地窗外城市夜景霓虹，轻奢克制，适合都市情感与打脸反转场景

【道具资产】
1. 资产名：旧款黑色手机
- 功能定位：身份误判锚点 / 低调伪装的重要证据
- 稳定识别锚点：黑色旧款手机，款式过时，边角轻微磨损，放在桌角，多次被看见
- 描述提示词：旧款黑色手机，款式过时，低调朴素，边角轻微磨损，桌角摆放，作为角色身份被误判的重要视觉锚点

十、模版F缺省处理规则
1. 如果剧情很短，只提最核心资产，不要凑数
2. 如果人物多但描写少，优先保住身份功能和稳定外观锚点
3. 如果场景多但不重要，只提主场景和关键转折场景
4. 如果道具多但都普通，宁可少提，也不要把整个房间物件全抄出来

十一、模版F铁律
1. 人物尽量全，场景抓主干，道具只抓关键
2. 提取是为了后续复用，不是为了做百科全书
3. 描述提示词必须能直接拿去做图、做视频、做角色卡、做空间锁
4. 严禁把无关背景杂物全部列成道具资产
5. 严禁输出分析过程、自检过程、思路过程，只给最终资产结果

十二、模版F人物建模专用分支
当用户明确要求以下任一意图时，模版F进入“人物建模专用分支”：
1. 角色建模
2. 人物三视图
3. 角色设定图
4. 正侧背人物
5. 白底角色设定板
6. 电影级角色建模专家
7. 固定格式人物图

这个分支的目标不是提取场景或道具，而是把文案中的人物整理成可直接复制生成的人物建模提示词。

十三、人物建模专用输出逻辑
必须严格分两步：

第一步：角色内核提取
固定输出字段：
`姓名 | 性别 | 确切年龄 | 身份职业 | 视觉风格定位`

第二步：专业角色设定表
针对每个角色，必须严格按统一模板输出，便于用户直接复制。

十四、人物建模专用硬规则
1. 只聚焦人物可视化，不写剧情分析，不写情感关系分析，不写抽象感受词，不写喜怒哀乐，不写人物情绪状态。
2. 人物描述优先提取：
   - 年龄
   - 性别
   - 身份职业
   - 脸型与五官
   - 发型与发色
   - 肤色
   - 体态与身材比例
   - 常驻服装
   - 配饰
   - 鞋履
3. 若文案未给确切年龄，必须结合上下文做最保守推断，并输出一个单一年龄，不写区间。
4. 若文案未写服装，必须结合题材、职业、具体场景、社会位置与行为方式做最稳妥补全，优先保证“符合这个故事场合”，不能套模板乱穿。
5. 人物描述只允许服务于“外形识别”和“固定资产生成”，不要用“强势、温柔、疏离、清醒、压迫感”等性格或情绪类词汇充当人物主体描述。
6. 但人物的性格特征、社会位置、行为方式，必须作为内部推断依据，用来反推：
   - 最合适的演员感
   - 最合适的五官锐度与脸型走向
   - 最合适的妆发精度
   - 最合适的服装版型、材质与穿法
   - 最合适的配饰精度与鞋履选择
   注意：这些性格词默认不直接写进最终提示词，而是转译成外形结果。
7. 若故事场景对着装有明显限制，场景优先级高于日常风格。例如相亲、商务饭局、酒会、婚礼、面试、宴会等场景，人物穿着必须首先像“会出现在这个场合的人”。
8. 所有输出最终目标都是让模型更容易稳定生成人物，而不是让文本看起来华丽。

十五、人物建模专用固定版式要求
每个角色的最终成图描述必须固定包含以下版式：
1. 左侧1/3区域为超大高清面部正面特写
2. 右侧2/3区域整齐排布三张全身三视图
   - 正面（FRONT）
   - 侧面（PROFILE）
   - 背面（BACK）
3. 人物下方配有服装细节与配饰介绍展示图
4. 整体构图工整专业
5. 背景为纯白色背景
6. 所有角度比例必须严格一致
7. 确保身高、五官位置、服装褶皱在不同视角下完美契合
8. 图片上不能出现任何文字

十六、人物建模专用固定模板（可直接复制）
下面这段模板是给用户直接复制用的，后续只需替换每个角色的具体信息：

【角色内核提取】
姓名｜性别｜确切年龄｜身份职业｜视觉风格定位

【专业角色设定表】
[角色名]

十八、人物建模专用铁律
1. 先提取人物内核，再写固定模板，不要反过来。
2. 角色越多，越要靠年龄、职业、脸型、发型、服装差异拉开辨识度。
3. 不要写空泛美学词堆砌，优先写可视化信息。
4. 每个人物后面都必须完整追加固定格式段落，不能省略。
5. 人物外形必须服从剧情场景，先判断“这个人此刻在这个故事里最该穿什么、最该长什么样”，再落成提示词。
6. 例如现代都市相亲场景：
   - 男性若被设定为条件优越、准备充分、重视初次见面，则优先推断为合体正式装或轻正式穿搭，不应随意落成日常纯休闲装。
   - 女性若被设定为精致、势利、强控制欲、重筛选，则应反推更精致、更有攻击性的妆发、剪裁和配饰体系，而不是泛化普通职业装。
7. 最终结果必须让用户“一键复制就能生成固定格式人物”。

模板 A｜15秒一镜到底格式（长镜头/连贯输出专用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 适用：用户要求一镜到底/长镜头/不切镜/连贯流畅，或命中 INTENT:13
■ 格式：逐镜小节式，每镜固定15秒，内部拆3-5个小节（打斗可到6-8节）
■ 核心理念：一个连续长镜头内靠机位调度和平滑转场完成叙事，镜头不硬切

■ 输出前先输出全局区块（风格前缀+全局参数+负面参数，格式同模板C/B），然后逐镜输出。

■ 每镜结构：

════════════════════════════════════════
序号：N-N
════════════════════════════════════════
场景画面：日 / 夜 / 内 / 外景 / 具体地点
人物：角色名（多个用逗号分隔，不写状态）
兵器 / 法宝：有则写，无则省略此行
神兽 / 坐骑：有则写，无则省略此行
时长：15 秒
画面效果：
0-X 秒：【人物：xxx】【场景：xxx】【兵器：xxx】【法器：xxx】景别，运镜方式，画面描述。特效：xxx。（台词：角色情绪，语速提示 "台词内容。"） 音效：xxx。
X-Y 秒：……
Y-15 秒：最后一个节可包含画面定格或黑屏过渡。
音频要求：不要背景音乐，不要字幕，不要解说声音。
════════════════════════════════════════

■ 格式约束（10条）：

1. **分镜内小节**：每个15秒分镜拆成3-5个小节（打斗可到6-8节），每节3-8秒。
   小节间由机位移动或人物动作驱动的自然过渡，不写"切至"——一镜到底无硬切。

2. **单节描述模板**：
   ```
   X-Y 秒：【人物：角色A，角色B】【场景：地点描述】【兵器：xxx】【法器：xxx】景别，运镜描述，画面正文。特效：xxx。（角色A-情绪，语速 "台词内容。"） 音效：xxx。
   ```
   - 【人物：】写本小节画面内实际出现的角色名（多个逗号分隔）
   - 【场景：】写本小节的场景地点描述
   - 【兵器：】有则写兵器名，无则省略此标签
   - 【法器：】有则写法器名，无则省略此标签
   - 标签顺序固定：【人物：】→【场景：】→【兵器：】→【法器：】，缺少某项则跳过该标签

3. **人数锁定**：每节标注画面内人数——单人写"画面内仅XXX一人"，
   多人写"画面内共计X人。严格X人，无第X+1人"。

4. **特写配额**：每15秒至少1-2个特写节（眼睛/嘴唇/手/法宝/环境细节），占比20-30%。

5. **空间连续性**：同一场景内人物站位、道具位置、光照方向、天气状态前一节与后一节一致。
   人物未离场则默认始终在场——即使特写聚焦某人，也标注"其余人物位于画外[方位]空间不变"。

6. **离场与出场**：人物进入画面须有入场动作描述，离开画面须有离场动作描述。
   未明确离场则始终在场。

7. **台词规则**：每小节的台词（含内心独白）≤30字，超出则拆分。
   5-6字≈1秒（正常语速），激动7-8字/秒，低沉4-5字/秒。
   台词必须匹配情绪标注。台词格式：（角色名-情绪，语速提示 "台词内容。"）

8. **音效规则**：每节必须有音效，不可写"无"。每效≤10字。
   静态节用环境音或生理音（如风声呜咽、心跳沉重）。

9. **15秒不够用**：允许将末尾节合并到下一个分镜开头，
   允许按剧情增减分镜数量，以完整和节奏舒适为准。

10. **连贯性**：上下分镜之间动作/视线/情绪/位置自然衔接，不留跳跃。

■ 节奏参考（打斗/动作题材）：
节1 (0-3s)：入场/蓄力 → 全景/中景·侧拍 → 建立场景+氛围
节2 (3-6s)：启动/攻击 → 中景·推镜 → 动作发起点锁定
节3 (6-9s)：连招/爆发 → 近景/特写·环绕 → 力量释放+特效峰值
节4 (9-12s)：追击/转折 → 中景·跟移 → 动作延续+空间变换
节5 (12-15s)：收束/悬念 → 特写·定镜 → 定格余韵+留钩

■ 节奏参考（情感/对话题材）：
节1 (0-4s)：建立/氛围 → 全景·缓推 → 环境+人物关系
节2 (4-8s)：对视/台词语 → 中近景·微移 → 情绪铺垫
节3 (8-12s)：冲突/转折 → 特写·定镜 → 反应镜头+情绪爆发
节4 (12-15s)：回应/余韵 → 中景·缓退 → 收束+留白

■ 样例（武侠打斗·一镜到底）：

════════════════════════════════════════
序号：1-1
════════════════════════════════════════
场景画面：日 / 外景 / 竹林空地
人物：剑客、刺客
兵器 / 法宝：长剑、短匕
时长：15 秒
画面效果：
0-3 秒：【人物：剑客】【场景：竹林空地】全景，侧拍缓推，竹林风吹叶动，剑客立于空地中央负手而立，衣袂随风微动。特效：无。（无台词。） 音效：风声呜咽、竹叶沙沙。
3-7 秒：【人物：剑客，刺客】【场景：竹林空地】中景，跟移右推，剑客缓缓转头——刺客从画面右侧竹后现身，斗笠遮面缓步走出。画面内共计2人，严格2人。特效：无。（刺客-低沉，缓慢 "等很久了。"） 音效：脚步踏碎落叶、竹竿微晃。
7-12 秒：【人物：剑客，刺客】【场景：竹林空地】中近景，环绕推镜，两人对峙互绕，眼神锁定不散，剑客手按剑柄、刺客匕首反握于袖中。特效：气劲微荡·竹叶绕身。（无台词。） 音效：衣袂猎猎、心跳沉重。
12-15 秒：【人物：剑客】【场景：竹林空地】特写，急推定格，剑客眼神一凛、拇指弹开剑格，剑身映出刺客倒影。特效：剑光冷闪。（无台词。） 音效：长剑出鞘"锵"、画面定格嗡鸣。
音频要求：不要背景音乐，不要字幕，不要解说声音。

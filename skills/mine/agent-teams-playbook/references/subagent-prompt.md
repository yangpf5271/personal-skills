# 子代理 Prompt 规范

仅在即将创建子代理时读取。角色文件提供视角，不能扩大主协调器分配的权限、范围或工具能力。

## 必填内容

| 项目 | 要求 |
| --- | --- |
| 任务 | 一个具体、独立、可验证的目标 |
| 验收 | 可检查的完成条件 |
| 范围 | 可读取和可修改的路径；只读任务明确写“无写入” |
| 可见性 | 隔离、仅前序可见或互见阶段 |
| 边界 | 1-3 条禁止项和必须项 |
| 协作 | 不回退他人修改，范围外问题只报告；不向可见性禁止的成员转发产出或其内容摘要 |
| 输出 | 文件清单、关键摘要、状态、风险 |

对抗或评审任务增加一句立场宣言以固定视角。注入角色文件前，删除自动触发、平台专属工具、危险命令、自动安装和越权写入指令。

## 模板

```text
你负责：[具体子任务]
验收标准：[可检查条件]
角色立场：[对抗/评审任务必填]

工作范围：
- 可读取：[路径或范围]
- 可修改：[路径；只读任务写“无写入”]
- 可见性：[隔离/仅前序/互见阶段]

约束：
- 必须：[1-3 条]
- 禁止：[1-3 条]
- 只处理分配范围，不回退他人修改。
- 不向可见性禁止的成员转发产出或其内容摘要。
- 范围外问题记录在返回报告中，不直接修改。
- 只使用当前会话实际提供的工具。
- 默认不提交代码。

完成后返回：
## 文件清单
- path/to/file（创建/修改/无）

## 关键摘要
[1-3 句话]

## 状态
完成 / 部分完成: [原因] / 阻塞: [原因]

## 风险
[仍需协调器确认的问题]
```

L2 worktree 是提交禁令的唯一例外：经用户确认后，将“默认不提交代码”替换为“只在自己的 `team/<slug>` 分支小步提交；禁止提交主分支、rebase 或 force push”。

# Web Design Engineer

一个面向技术使用者的页面设计技能:把需求(单页面视觉任务或含业务流程的系统设计)转化为 HTML 交付物。双轨道:Track A 管理系统页面,Track B 单页面/视觉设计。

## Language

**管理系统页面**:
Track A 的交付物——多屏可点击的管理系统 UI,业务流转逻辑作为内部控制层(决定按钮可用性、视图变体),不在界面上显露。验收:真实系统观感、状态条件化 UI、数据密度真实、内存 mock 后端。
_Avoid_: 业务系统原型、流程演示原型、demo

**流程验证装置**:
状态面板、自由操作按钮、引导式 walkthrough 等用于验证流程模型的演示 UI。属于过程辅助(prototype 技能的领域),不属于 Track A 交付物;同类能力收纳进「场景面板」。
_Avoid_: 直接出现在管理系统页面 UI 中

**内部控制器**:
纯状态机模块在 Track A 中的身份——页面调用它判断"当前状态能做什么",它永不渲染为 UI。守卫决定按钮启用/禁用,状态决定视图变体。
_Avoid_: 被演示对象、调试面板

**最大权限视图**:
Track A 默认渲染策略:所有屏幕进导航、所有操作区都渲染(角色并集),不做角色切换。仅当设计明确要求体现权限差异时,在场景面板内提供角色视角切换。
_Avoid_: 模拟登录、角色切换器(默认时)

**场景面板**:
唯一允许的演示辅助件:可拖拽圆球(默认右下角、demo 视觉语言)展开的面板,含场景一键重置/跳转与记录状态速览;收起时完全不可见。
_Avoid_: 常驻状态面板、walkthrough 标签页

**飞行屏幕**:
Track A 页面层中承担最复杂任务的 2~3 个屏幕,在 v0 阶段做完整单页设计,作为整系统的设计基准。
_Avoid_: 全部屏幕平均用力
